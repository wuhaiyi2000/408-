# 408计算机组成原理：数据通路常见硬件部件速查

## 一、核心寄存器与控制部件

| 部件名称 | 英文缩写 | 主要功能 |
|---|---|---|
| 程序计数器 | PC | 保存下一条待执行指令的地址 |
| 指令寄存器 | IR | 保存当前正在执行的指令 |
| 存储器地址寄存器 | MAR | 保存要访问的主存地址 |
| 存储器数据寄存器 | MDR | 暂存从主存读出或写入主存的数据 |
| 通用寄存器组 | GPR | 保存操作数和运算结果 |
| 标志寄存器 | PSW | 保存进位、零、符号、溢出等状态标志 |
| 控制器 | CU | 产生控制信号，协调各部件工作 |
| 暂存寄存器 | A、B | 暂存ALU运算的操作数 |

### 重点记忆

- PC：存指令地址。
- IR：存指令内容。
- MAR：存主存地址。
- MDR：存主存数据。
- GPR：存操作数和运算结果。
- PSW：存运算状态标志。
- CU：产生控制信号。

## 二、数据通路常见功能部件

| 部件名称 | 英文名称 | 主要功能 |
|---|---|---|
| 算术逻辑单元 | ALU | 执行算术运算和逻辑运算 |
| 加法器 | Adder | 完成两个操作数相加 |
| 移位器 | Shifter | 对二进制数据进行左移或右移 |
| 多路选择器 | MUX | 从多个输入中选择一个输出 |
| 符号扩展器 | Sign Extension | 扩展数据位数并保留符号 |
| 零扩展器 | Zero Extension | 扩展数据位数，高位补0 |
| 译码器 | Decoder | 将输入编码译码为对应控制信号 |
| 比较器 | Comparator | 比较两个操作数是否相等或大小关系 |
| 缓冲器 | Buffer | 暂存数据或增强信号驱动能力 |
| 三态门 | Tri-state Gate | 控制信号是否允许通过总线 |

### 重点功能

1. ALU：执行加、减、与、或、异或等运算。
2. 加法器：负责加法运算，也可用于PC自增和地址计算。
3. 移位器：负责逻辑移位、算术移位等操作。
4. MUX：根据控制信号选择不同输入。
5. 符号扩展器：复制原数据的符号位。
6. 零扩展器：在高位补0。
7. 译码器：根据输入编码产生对应输出。
8. 比较器：判断两个数是否相等或大小关系。

## 三、常见硬件部件的输入与输出

| 部件 | 输入 | 输出 |
|---|---|---|
| PC | 下一地址、选择信号 | 当前指令地址 |
| IR | 取出的指令 | 指令各字段 |
| MAR | 主存访问地址 | 主存地址 |
| MDR | 主存读出数据或待写数据 | 数据总线上的数据 |
| ALU | 两个操作数、运算控制信号 | 运算结果、状态标志 |
| 加法器 | 两个操作数 | 相加结果 |
| 移位器 | 待移位数据、移位控制 | 移位结果 |
| MUX | 多个数据输入、选择信号 | 被选中的数据 |
| 符号扩展器 | 原始数据 | 符号扩展后的数据 |
| 零扩展器 | 原始数据 | 高位补0后的数据 |
| 译码器 | 输入编码 | 译码结果 |
| 比较器 | 两个操作数 | 比较结果 |

## 四、容易混淆的部件对比

### 1. PC与IR

| 部件 | 存储内容 |
|---|---|
| PC | 下一条待执行指令的地址 |
| IR | 当前正在执行的指令内容 |

### 2. MAR与MDR

| 部件 | 存储内容 |
|---|---|
| MAR | 主存地址 |
| MDR | 主存数据 |

记忆：MAR存地址，MDR存数据。

### 3. ALU与加法器

| 部件 | 功能 |
|---|---|
| ALU | 执行多种算术和逻辑运算 |
| 加法器 | 专门执行加法运算 |

加法器可以作为ALU内部的组成部分，也可以作为独立的数据通路部件。

### 4. 加法器与移位器

| 部件 | 功能 |
|---|---|
| 加法器 | 两个数相加 |
| 移位器 | 二进制数左移或右移 |

例如：

- 左移1位：相当于乘以2（不考虑溢出）。
- 左移2位：相当于乘以4（不考虑溢出）。

### 5. 符号扩展与零扩展

| 类型 | 扩展方式 | 适用情况 |
|---|---|---|
| 符号扩展 | 高位复制原符号位 | 有符号数 |
| 零扩展 | 高位全部补0 | 无符号数 |

例如，将8位数据扩展为16位：

- 符号扩展：10000001 -> 1111111110000001
- 零扩展：10000001 -> 0000000010000001

### 6. 寄存器与多路选择器

| 部件 | 功能 |
|---|---|
| 寄存器 | 存储数据 |
| MUX | 选择数据 |

MUX本身不负责保存数据。

### 7. 译码器与控制器

| 部件 | 功能 |
|---|---|
| 译码器 | 将输入编码转换为对应输出 |
| 控制器 | 根据指令产生和组织控制信号 |

## 五、结合条件转移指令理解数据通路

以条件转移指令为例：

`目标地址 = PC + 2 + OFFSET × 2`

对应硬件部件：

| 执行过程 | 使用的部件 | 功能 |
|---|---|---|
| 保存当前指令 | IR | 保存指令内容 |
| 读取状态标志 | PSW | 提供CF、ZF、NF |
| 提取偏移量 | IR | 提取OFFSET字段 |
| 扩展偏移量 | 符号扩展器 | 将OFFSET扩展到目标位数 |
| 偏移量乘2 | 移位器 | 左移1位 |
| 计算PC+2 | 加法器 | 得到顺序执行地址 |
| 计算目标地址 | 加法器 | PC+2与偏移量相加 |
| 判断是否转移 | 与门、或门 | 判断条件是否满足 |
| 选择下一条地址 | MUX | 选择顺序地址或转移地址 |
| 更新指令地址 | PC | 保存新的指令地址 |

### 条件转移的核心公式

`目标地址 = PC + 2 + OFFSET × 2`

转移条件：

`(C AND CF) OR (Z AND ZF) OR (N AND NF)`

注意：

- 移位器负责移位。
- 加法器负责加法。
- MUX负责选择。
- PC负责保存下一条指令地址。

## 七、考研速记

| 看到的功能 | 对应部件 |
|---|---|
| 保存下一条指令地址 | PC |
| 保存当前指令 | IR |
| 保存主存访问地址 | MAR |
| 保存主存读写数据 | MDR |
| 执行算术逻辑运算 | ALU |
| 保存运算状态 | PSW |
| 两个数相加 | 加法器 |
| 二进制左移或右移 | 移位器 |
| 多个输入选择一个 | MUX |
| 扩展补码且保留符号 | 符号扩展器 |
| 高位补0 | 零扩展器 |
| 指令操作码译码 | 译码器 |
| 比较两个数 | 比较器 |
| 控制信号协调 | CU |

**核心记忆原则：**

1. 存储类部件：记住存什么。
2. 运算类部件：记住做什么运算。
3. 控制类部件：记住如何控制。
4. 选择类部件：记住如何选择输入输出。

做数据通路框图题时，重点分析每个部件的输入、处理过程和输出，就能更容易判断空缺部件的名称。
