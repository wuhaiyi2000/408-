# 408 计算机组成原理：数值表示与运算考点整理

> 本笔记覆盖进位计数制、无符号数、有符号数、原码/反码/补码、补码运算与溢出、定点数、IEEE
> 754 单精度浮点数及 BCD 码。

## 一、进位计数制与数制转换

### 1. 常见进制

  进制         基数 数字符号
  ---------- ------ ------------
  二进制          2 0、1
  八进制          8 0～7
  十进制         10 0～9
  十六进制       16 0～9、A～F

十六进制中 A=10、B=11、C=12、D=13、E=14、F=15。

### 2. 任意进制转十进制：按位权展开

例如：

\[
(1011.01)\_2=1`\times2`{=tex}^3+0`\times2`{=tex}^2+1`\times2`{=tex}^1+1`\times2`{=tex}^0+0`\times2`{=tex}^{-1}+1`\times2`{=tex}^{-2}=11.25
\]

整数部分从右向左，位权从 (2\^0) 开始递增；小数部分从左向右，位权从
(2\^{-1}) 开始递减。

### 3. 十进制整数转二进制：除 2 取余，逆序排列

例如 13：

``` text
13 ÷ 2 = 6 余 1
 6 ÷ 2 = 3 余 0
 3 ÷ 2 = 1 余 1
 1 ÷ 2 = 0 余 1
```

从下向上读取余数：

\[ (13)\_{10}=(1101)\_2 \]

### 4. 十进制小数转二进制：乘 2 取整，正序排列

例如 0.625：

``` text
0.625 × 2 = 1.25  取整数 1
0.25  × 2 = 0.5   取整数 0
0.5   × 2 = 1.0   取整数 1
```

从上向下读取整数部分：

\[ (0.625)\_{10}=(0.101)\_2 \]

有些十进制小数转换为二进制后会无限循环，例如
0.1，因此计算机只能保存有限位，可能产生舍入误差。

### 5. 二进制与八进制、十六进制快速转换

-   二进制转八进制：从小数点向两侧每 3 位分组，不足补 0。
-   二进制转十六进制：从小数点向两侧每 4 位分组，不足补 0。

例如：

\[ (11010110)\_2=(326)*8=(D6)*{16} \]

## 二、无符号数与有符号数

### 1. 无符号数

n 位无符号数的范围：

\[ `\boxed{0\leq X\leq2^n-1}`{=tex} \]

例如 8 位无符号数范围为 0～255。所有位都表示数值，没有专门的符号位。

### 2. 有符号数

在原码、反码、补码中，最高位通常作为符号位：

-   0：正数或零；
-   1：负数。

但符号位为 1 时，数值如何解释取决于编码方式。

## 三、原码、反码、补码

这是 408 数值表示的核心考点。

### 1. 三种编码的定义

设机器字长为 n 位，最高位为符号位。

**原码：** - 正数：符号位为 0，数值位表示绝对值。 - 负数：符号位为
1，数值位仍表示绝对值。

**反码：** - 正数：与原码相同。 - 负数：符号位不变，数值位按位取反。

**补码：** - 正数：与原码、反码相同。 - 负数：在反码基础上加 1。

以 8 位表示 13 和 -13 为例：

    真值 原码       反码       补码
  ------ ---------- ---------- ------------------
     +13 00001101   00001101   00001101
     -13 10001101   11110010   11110011
      +0 00000000   00000000   00000000
      -0 10000000   11111111   不存在独立的负零

### 2. 负数补码的快捷求法

求负数补码：

1.  写出对应正数的二进制；
2.  各位取反；
3.  最低位加 1。

例如，求 8 位 -13 的补码：

``` text
+13：00001101
取反：11110010
加 1：11110011
```

也可以使用公式：

\[ `\boxed{[-X]_{\text{补}}=2^n-X}`{=tex} \]

其中 n 为机器字长，结果保留 n 位。

### 3. 三种编码的表示范围

  编码方式   n 位表示范围                                0 的个数
  ---------- ----------------------------------------- ----------
  无符号数   (0`\sim`{=tex}2\^n-1)                              1
  原码       (-(2^{n-1}-1)`\sim `{=tex}+(2^{n-1}-1))            2
  反码       (-(2^{n-1}-1)`\sim `{=tex}+(2^{n-1}-1))            2
  补码       (-2^{n-1}`\sim `{=tex}+(2^{n-1}-1))                1

以 8 位为例：

-   无符号数：0～255；
-   原码：-127～+127；
-   反码：-127～+127；
-   补码：-128～+127。

**补码比原码、反码多表示一个负数，即最小负数 (-2\^{n-1})。**

### 4. 已知编码，如何还原真值？

  编码   最高位为 0           最高位为 1
  ------ -------------------- ----------------------------------
  原码   数值位直接表示正数   数值位表示绝对值，加负号
  反码   直接按正数解释       数值位取反，得到绝对值，加负号
  补码   直接按正数解释       各位取反加 1，得到绝对值，加负号

例：

``` text
11110011（补码）
取反：00001100
加 1：00001101
真值：-13
```

也可以使用补码权值展开。n 位补码最高位权值为
(-2\^{n-1})，其余位权值为正：

\[ X=-a\_{n-1}2\^{n-1}+`\sum`{=tex}\_{i=0}^{n-2}a_i2^i \]

例如：

\[ (11110011)\_2=-128+64+32+16+2+1=-13 \]

### 5. 为什么计算机使用补码？

1.  正数的补码与原码相同，表示简单。
2.  0 只有一种表示。
3.  加法和减法可以统一使用加法器完成。
4.  符号位可以参与运算，简化硬件设计。

## 四、补码运算与溢出判断

### 1. 补码加法

\[ `\boxed{[A+B]_{\text{补}}=[A]_{\text{补}}+[B]_{\text{补}}}`{=tex} \]

计算结果只保留规定的 n 位，最高位之外的进位丢弃。

例：8 位补码计算 (13+(-5))：

``` text
  00001101
+ 11111011
------------
1 00001000
```

丢弃最高位进位，结果为：

``` text
00001000 = +8
```

### 2. 补码减法

减法转换为加法：

\[ `\boxed{[A-B]_{\text{补}}=[A]_{\text{补}}+[-B]_{\text{补}}}`{=tex} \]

例：8 位补码计算 (7-3)：

``` text
  00000111
+ 11111101
------------
1 00000100
```

丢弃最高位进位，结果为 +4。

### 3. 补码溢出

溢出指运算结果超出当前机器字长所能表示的范围。

以 8 位补码为例，范围是 -128～+127。若计算
(100+50=150)，则发生有符号溢出。

**方法一：看操作数和结果的符号**

两个同号数相加，若结果符号与操作数不同，则发生溢出。

  A    B    结果   是否溢出
  ---- ---- ------ ------------------------
  正   正   负     是
  负   负   正     是
  正   负   任意   不会因有符号范围而溢出
  负   正   任意   不会因有符号范围而溢出

**方法二：看符号位的进位**

\[ `\boxed{OF=C_{\text{符号位输入}}\oplus C_{\text{符号位输出}}}`{=tex}
\]

符号位输入进位与输出进位不同，则发生溢出；相同则不溢出。

### 4. CF 与 OF 不要混淆

  标志    含义                       主要用于
  ------- -------------------------- ------------------
  CF      进位/借位相关标志          无符号数运算
  OF      有符号数溢出标志           有符号数运算
  ZF      零标志，结果是否为 0       判断结果是否为零
  SF/NF   符号标志，反映结果最高位   判断结果符号

关键： - CF=1 不代表有符号数一定溢出。 - OF=1 不代表无符号数一定越界。 -
同一次运算可以 CF=1、OF=0，也可以 CF=0、OF=1。

### 5. 符号扩展

将较短的有符号数扩展为更长位数时，复制原符号位：

-   正数：高位补 0；
-   负数：高位补 1。

例如，8 位补码 -5：

``` text
11111011
```

扩展为 16 位：

``` text
11111111 11111011
```

**补码符号扩展：复制原符号位，保持真值不变。**

## 五、定点数

### 1. 定点数的含义

定点数的小数点位置固定。约定小数点在最低位之后，可以表示整数；约定小数点在某些位之间，可以表示固定精度的小数。

定点数通常采用原码、反码或补码表示。

### 2. 定点数特点

-   硬件实现相对简单；
-   运算通常较简单；
-   小数点位置固定；
-   表示范围和精度受到固定格式限制。

### 3. 定点数与浮点数对比

  对比         定点数                     浮点数
  ------------ -------------------------- ------------------------
  小数点位置   固定                       由阶码动态确定
  表示范围     相对较小                   范围较大
  运算复杂度   相对简单                   相对复杂
  精度         取决于固定小数位数         有效位数有限
  常见用途     特定数值计算、嵌入式场景   科学计算、通用浮点运算

## 六、IEEE 754 单精度浮点数

这是 408
数值表示重点，尤其要掌握字段划分、阶码偏置、规格化、真值还原和特殊值。

### 1. 单精度浮点数的字段组成

IEEE 754 单精度浮点数共 32 位：

  字段            位数 作用
  ------------ ------- ------------------------
  符号位 S        1 位 表示正负
  阶码 E          8 位 表示指数，采用偏置表示
  尾数字段 F     23 位 保存有效数的小数部分
  合计           32 位 4 字节

``` text
31             30              23 22                         0
+----------------+----------------+----------------------------+
|   符号位 S     |    阶码 E      |       尾数字段 F            |
|      1位       |      8位       |          23位               |
+----------------+----------------+----------------------------+
```

### 2. 规格化数的表示公式

当阶码字段 E 既不全 0，也不全 1 时，表示规格化数：

\[ `\boxed{X=(-1)^S\times(1.F)_2\times2^{E-127}}`{=tex} \]

其中： - S：符号位，0 正、1 负； - E：8 位阶码字段对应的无符号整数； -
127：单精度阶码偏置值； - 1.F：最高位 1 隐含，不需要存储。

**23 位尾数字段加上隐藏的最高位 1，规格化数实际有 24
位二进制有效精度。**

### 3. 为什么阶码要加 127？

实际指数 e 与阶码字段 E 的关系：

\[ `\boxed{E=e+127}`{=tex} \]

反过来：

\[ `\boxed{e=E-127}`{=tex} \]

例如实际指数为 +3：

\[ E=3+127=130=(10000010)\_2 \]

所以阶码字段为 `10000010`。

### 4. 单精度浮点数的表示范围

规格化数实际指数范围：

\[ -126`\leq `{=tex}e`\leq127`{=tex} \]

最小正规格化正数：

\[ `\boxed{2^{-126}\approx1.17549435\times10^{-38}}`{=tex} \]

最大有限正数：

\[ `\boxed{(2-2^{-23})\times2^{127}\approx3.4028235\times10^{38}}`{=tex}
\]

最小正非规格化数：

\[ `\boxed{2^{-149}}`{=tex} \]

单精度浮点数通常约有 7 位十进制有效数字。

### 5. 十进制数转换为单精度浮点数：13.25 示例

**第一步：转换为二进制。**

\[ 13=(1101)\_2,`\quad0.25`{=tex}=(0.01)\_2 \]

所以：

\[ 13.25=(1101.01)\_2 \]

**第二步：规格化。**

\[ 1101.01=1.10101`\times2`{=tex}\^3 \]

因此： - S=0； - 实际指数 e=3； - 有效数为 1.10101。

**第三步：计算阶码。**

\[ E=e+127=3+127=130=(10000010)\_2 \]

**第四步：填写尾数字段。**

规格化有效数：

``` text
1.10101000000000000000000
```

最高位的 1 隐含，不存储。23 位尾数字段为：

``` text
10101000000000000000000
```

**第五步：拼接 32 位。**

``` text
0 | 10000010 | 10101000000000000000000
```

十六进制表示：

``` text
41540000H
```

因此：

\[ `\boxed{13.25\text{ 的 IEEE 754 单精度表示为 }41540000H}`{=tex} \]

### 6. 已知浮点编码，如何还原真值？

例如：

``` text
0 | 10000010 | 10101000000000000000000
```

依次分析： 1. S=0； 2. E=130； 3. 实际指数 e=130-127=3； 4. 有效数为
1.10101（二进制）。

所以：

\[ X=(1.10101)\_2`\times2`{=tex}\^3 =(1101.01)\_2=13.25 \]

### 7. 阶码字段的特殊情况

不能把所有阶码字段都直接套用 (E-127)。

  阶码 E               尾数字段 F   表示意义
  -------------------- ------------ ----------------
  全 0                 全 0         正零或负零
  全 0                 不全 0       非规格化数
  既不全 0，也不全 1   任意         规格化有限数
  全 1                 全 0         正无穷或负无穷
  全 1                 不全 0       NaN，非数

**规格化数：**

\[ X=(-1)\^S`\times`{=tex}(1.F)\_2`\times2`{=tex}\^{E-127} \]

**非规格化数：**

\[ `\boxed{X=(-1)^S\times(0.F)_2\times2^{-126}}`{=tex} \]

非规格化数没有隐藏的最高位 1，而是使用 0.F。

**正零和负零：** E=0、F=0；S=0 为 +0，S=1 为 -0。

**无穷大：** E 全 1、F 全 0；S 决定正无穷或负无穷。

**NaN：** E 全 1、F 不全 0。

### 8. 单精度浮点数的精度问题

浮点数尾数位数有限，不能精确表示所有实数。

例如十进制 0.1
的二进制展开是无限循环的，单精度只能保存近似值，因此可能产生舍入误差。

浮点数加法还可能不满足严格的数学结合律：

\[ (a+b)+c`\ne `{=tex}a+(b+c) \]

原因是中间结果可能发生舍入。

## 七、浮点数运算的基本步骤

### 1. 浮点数加减法

通常遵循：

1.  对阶：使两个数的阶码相同；
2.  尾数运算：对有效数进行加减；
3.  规格化：调整有效数和阶码；
4.  舍入：处理多余位；
5.  判断溢出或下溢。

**对阶原则：小阶向大阶看齐。**

例如：

\[ 1.01`\times2`{=tex}^3+1.10`\times2`{=tex}^1 \]

将第二个数的阶码从 1 调整为 3：

\[ 1.10`\times2`{=tex}^1=0.0110`\times2`{=tex}^3 \]

再进行尾数相加：

\[ (1.0100+0.0110)`\times2`{=tex}\^3 =1.1010`\times2`{=tex}\^3 \]

### 2. 浮点数乘除法

-   乘法：阶码相加，尾数相乘，再规格化和舍入。
-   除法：阶码相减，尾数相除，再规格化和舍入。

## 八、BCD 码

BCD（Binary-Coded Decimal，二进制编码的十进制数）常见的是 8421 BCD 码。

### 1. 基本规则

每个十进制数字单独用 4 位二进制表示。

    十进制 8421 BCD
  -------- ----------
         0 0000
         1 0001
         2 0010
         3 0011
         4 0100
         5 0101
         6 0110
         7 0111
         8 1000
         9 1001

1010～1111 不属于有效的 8421 BCD 数字编码。

### 2. 示例：十进制 59

``` text
5       9
0101    1001
```

所以 59 的 BCD 编码为：

``` text
01011001
```

但 59 的纯二进制表示是：

``` text
111011
```

**BCD
不是把整个十进制数直接转换为二进制，而是每一位十进制数字分别编码。**

## 九、常见题型的解题步骤

### 题型 1：已知真值，求原码、反码、补码

1.  确定机器字长；
2.  正数直接写二进制，最高位补 0；
3.  负数先写出对应正数；
4.  原码：符号位置 1，数值位不变；
5.  反码：负数数值位取反，符号位保持 1；
6.  补码：负数反码加 1。

### 题型 2：已知补码，求真值

1.  看最高位；
2.  最高位为 0，直接转换为正数；
3.  最高位为 1，按位取反加 1，结果加负号；
4.  注意最小负数，例如 8 位补码 `10000000` 表示 -128。

### 题型 3：判断补码运算是否溢出

优先使用： - 两个同号数相加，结果异号则溢出； -
或计算符号位输入进位与输出进位的异或。

不要只看最高位是否产生进位。

### 题型 4：已知浮点数十六进制编码，求真值

1.  将十六进制转换为 32 位二进制；
2.  拆分 S、E、F；
3.  判断 E 是否全 0 或全 1；
4.  若为规格化数，计算 (e=E-127)；
5.  代入浮点数公式；
6.  将二进制有效数转换为十进制。

### 题型 5：已知十进制数，求单精度浮点编码

1.  转换为二进制；
2.  写成 (1.F`\times2`{=tex}\^e) 的规格化形式；
3.  确定符号位；
4.  计算阶码 (E=e+127)；
5.  填写 23 位尾数字段；
6.  拼接 32 位，必要时转换为十六进制。

## 十、408 高频易错点

  -----------------------------------------------------------------------
  易错点                              正确结论
  ----------------------------------- -----------------------------------
  原码、反码、补码的正数表示不同      正数三者相同

  负数补码就是负数原码取反            错，负数补码是原码数值位取反后加 1

  8 位补码范围是 -127～+127           错，是 -128～+127

  补码有正零和负零                    错，补码只有一种零

  补码最高位为 1 就表示发生溢出       错，最高位为 1
                                      只说明结果按补码解释为负数

  补码扩展时高位补 0                  错，复制符号位

  阶码全 0 时也使用隐藏位 1           错，非规格化数使用 0.F

  阶码全 1 一定表示无穷大             错，尾数全 0 才是无穷大，尾数非零是
                                      NaN

  BCD 码等于纯二进制                  错，每位十进制数字分别用 4 位编码

## 十一、考前速记公式

### 1. n 位数表示范围

无符号数：

\[ 0`\sim`{=tex}2\^n-1 \]

原码、反码：

\[ -(2^{n-1}-1)`\sim `{=tex}+(2^{n-1}-1) \]

补码：

\[ -2^{n-1}`\sim `{=tex}+(2^{n-1}-1) \]

### 2. 补码

\[ \[-X\]\_{`\text{补}`{=tex}}=`\overline{[X]_{\text{补}}}`{=tex}+1 \]

\[
\[A-B\]*{`\text{补}`{=tex}}=\[A\]*{`\text{补}`{=tex}}+\[-B\]\_{`\text{补}`{=tex}}
\]

### 3. 补码溢出

\[ OF=C\_{`\text{in}`{=tex}}`\oplus `{=tex}C\_{`\text{out}`{=tex}} \]

### 4. 单精度浮点数

规格化数：

\[ X=(-1)\^S`\times`{=tex}(1.F)\_2`\times2`{=tex}\^{E-127} \]

非规格化数：

\[ X=(-1)\^S`\times`{=tex}(0.F)\_2`\times2`{=tex}\^{-126} \]

阶码：

\[ E=e+127 \]

### 5. 单精度字段

``` text
符号位：1 位
阶码：  8 位
尾数： 23 位
总计： 32 位
```

## 十二、复习顺序建议
