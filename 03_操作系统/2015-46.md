# 2015 年 408 真题：2015-46 二级页表与地址转换

> **核心考点：**
> 页大小、页框大小、虚拟地址空间、虚拟页面数量、二级页表占用空间、根据虚拟地址计算页目录号和页表索引。

## 一、题目条件

某计算机采用按字节编址，使用二级页表的分页存储管理方式。虚拟地址格式如下：

  字段     页目录号   页表索引   页内偏移量
  ------ ---------- ---------- ------------
  位数        10 位      10 位        12 位

第（2）问补充条件：页目录项占 4 字节，页表项占 4 字节。

第（3）问给出两个虚拟地址：

``` text
0100 0000H
0111 2048H
```

------------------------------------------------------------------------

## 二、第（1）问：页和页框的大小、虚拟地址空间大小

### 1. 页大小

页内偏移量为 12 位，因此一页包含：

``` text
2^12 = 4096 字节 = 4KB
```

所以页大小为 4KB。分页存储管理中，页和页框大小相等，因此页框大小也是
4KB。

### 2. 虚拟地址空间大小

虚拟地址总位数：

``` text
10 + 10 + 12 = 32 位
```

按字节编址，因此：

``` text
虚拟地址空间 = 2^32 字节 = 4GB
```

### 3. 虚拟空间共有多少页？

方法一：虚拟地址空间大小除以页大小。

``` text
虚拟页面数
= 2^32 / 2^12
= 2^20
= 1,048,576 页
```

方法二：直接看页号位数。

``` text
页号位数 = 页目录号位数 + 页表索引位数
         = 10 + 10
         = 20 位

虚拟页面数 = 2^20 页
```

**第（1）问答案：**

  项目                             答案
  -------------- ----------------------
  页大小                            4KB
  页框大小                          4KB
  虚拟地址空间                      4GB
  虚拟页面数量     2\^20 = 1,048,576 页

------------------------------------------------------------------------

## 三、第（2）问：页目录和页表共占多少页？

已知页目录项和页表项均为 4 字节。

### 1. 页目录占多少空间？

页目录号为 10 位，因此页目录有：

``` text
2^10 = 1024 个页目录项
```

每个页目录项占 4 字节：

``` text
页目录大小 = 1024 × 4
           = 4096 字节
           = 4KB
```

每页大小为 4KB，因此页目录占 1 页。

### 2. 一个二级页表占多少空间？

页表索引为 10 位，因此每个二级页表有：

``` text
2^10 = 1024 个页表项
```

每个页表项占 4 字节：

``` text
一个二级页表大小 = 1024 × 4
                 = 4096 字节
                 = 4KB
```

因此，一个二级页表占 1 页。

### 3. 一共需要多少个二级页表？

页目录有 1024
个目录项，每个目录项可以指向一个二级页表。若按完整覆盖整个虚拟地址空间计算，需要：

``` text
二级页表数量 = 2^10 = 1024 个
```

每个二级页表占 1 页，因此所有二级页表共占 1024 页。

### 4. 页目录和页表总共占多少页？

``` text
总页数 = 页目录占用页数 + 二级页表占用页数
       = 1 + 1024
       = 1025 页
```

**第（2）问答案：1025 页。**

注意：这里按完整配置、覆盖整个虚拟地址空间计算。实际系统采用稀疏映射时，不一定需要把所有二级页表都分配出来。

------------------------------------------------------------------------

## 四、第（3）问：两个虚拟地址转换时共访问多少个不同的二级页表？

给定虚拟地址：

``` text
地址 1：0100 0000H
地址 2：0111 2048H
```

虚拟地址格式：

``` text
| 页目录号 10 位 | 页表索引 10 位 | 页内偏移量 12 位 |
```

判断访问几个不同的二级页表，关键是比较两个地址的**页目录号**：

-   页目录号相同：通过同一个页目录项找到同一个二级页表；
-   页目录号不同：访问不同的二级页表。

### 1. 拆分第一个地址：01000000H

32 位二进制：

``` text
00000001 00000000 00000000 00000000
```

按 10 位、10 位、12 位拆分：

``` text
页目录号：0000000100
页表索引：0000000000
页内偏移：000000000000
```

转换为十进制：

``` text
页目录号 = 4
页表索引 = 0
页内偏移 = 0
```

### 2. 拆分第二个地址：01112048H

32 位二进制：

``` text
00000001 00010001 00100000 01001000
```

按 10 位、10 位、12 位拆分：

``` text
页目录号：0000000100
页表索引：0100010010
页内偏移：000001001000
```

转换为十进制：

``` text
页目录号 = 4
页表索引 = 274
页内偏移 = 72
```

### 3. 比较两个地址

  虚拟地址      页目录号   页表索引   页内偏移
  ----------- ---------- ---------- ----------
  01000000H            4          0          0
  01112048H            4        274         72

两个虚拟地址的页目录号都是
4，因此它们通过同一个页目录项找到同一个二级页表。

虽然页表索引不同，访问的是该二级页表中的不同页表项，但二级页表本身只有一个。

**第（3）问答案：共访问 1 个不同的二级页表。**

## 六、408 考点总结与易错点

### 1. 页大小

``` text
页大小 = 2^(页内偏移位数)
```

例如，页内偏移为 12 位：

``` text
页大小 = 2^12 = 4KB
```

### 2. 虚拟地址空间大小

按字节编址时：

``` text
虚拟地址空间大小 = 2^(虚拟地址总位数) 字节
```

32 位虚拟地址：

``` text
2^32 字节 = 4GB
```

### 3. 虚拟页面数量

``` text
虚拟页面数量
= 虚拟地址空间大小 / 页大小
= 2^(页目录号位数 + 页表索引位数)
```

本题：

``` text
2^(10+10) = 2^20 页
```

### 4. 页目录和页表占用空间

``` text
页目录大小 = 页目录项数量 × 每个页目录项大小

一个二级页表大小 = 页表项数量 × 每个页表项大小
```

再分别除以页大小，得到占用的页数。

### 5. 多个虚拟地址访问几个不同的二级页表

只需要比较它们的页目录号：

-   页目录号相同：同一个二级页表；
-   页目录号不同：不同的二级页表。

**注意：不同虚拟页面不一定对应不同二级页表。**
同一个二级页表可以包含多个不同的页表项，映射多个虚拟页面。

### 6. 本题最容易混淆的数量

  名称                         本题数量
  -------------------------- ----------
  虚拟地址空间                      4GB
  页大小                            4KB
  虚拟页面数                   2\^20 页
  页目录项数                   2\^10 个
  一个二级页表的页表项数       2\^10 个
  完整配置的二级页表数         2\^10 个
  页目录和所有二级页表占用      1025 页

**一句话记忆：页内偏移决定页大小；页目录号和页表索引共同决定虚拟页面数量；页目录号决定访问哪个二级页表。**
