# 2010-46 请求分页管理中的 FIFO 与 CLOCK 页面置换

## 一、基本信息

-   **一级主要考点：** 操作系统------内存管理
-   **二级考点：**
    请求分页存储管理、逻辑地址划分、固定分配、局部置换、FIFO
    页面置换、CLOCK 页面置换、访问位、物理地址计算。
-   **题目分值：** 8 分
-   **题目类型：** 综合应用题（页面置换与地址转换）

## 二、题目条件整理

### 1. 原题

**2010 年第 46 题（8 分）**

某计算机的逻辑地址空间和物理地址空间均为
64KB，按字节编址。某进程最多需要 6 页数据存储空间，页面大小为
1KB。操作系统采用固定分配、局部置换策略，为该进程分配 4 个页框。

时刻 260 前，该进程的访问情况如下：

    页号   页框   装入时间   访问位
  ------ ------ ---------- --------
       0      7        130        1
       1      4        230        1
       2      2        200        1
       3      9        160        1

时刻 260，该进程要访问逻辑地址 17CAH。回答：

1.  该逻辑地址对应的页号是多少？
2.  若采用 FIFO 置换算法，该逻辑地址对应的物理地址是多少？给出计算过程。
3.  若采用 CLOCK
    置换算法，该逻辑地址对应的物理地址是多少？给出计算过程。搜索指针按顺时针方向移动，初始指向当前
    2 号页框（题图所示）。

### 2. 已知条件汇总

  项目                 条件
  -------------------- ------------------------
  逻辑地址空间         64KB
  物理地址空间         64KB
  编址方式             按字节编址
  页面大小             1KB = 1024B = 400H
  进程最多需要的页面   6 页，页号 0～5
  分配给进程的页框数   4 个
  分配方式             固定分配
  置换方式             局部置换
  当前时刻             260
  待访问逻辑地址       17CAH
  当前驻留页面         页 0、页 1、页 2、页 3
  当前访问位           均为 1

### 3. 当前页面状态

    页号   页框号   装入时间   访问位
  ------ -------- ---------- --------
       0        7        130        1
       1        4        230        1
       2        2        200        1
       3        9        160        1

该进程当前占用 4 个页框，分别为
7、4、2、9。固定分配意味着发生缺页时，不能增加该进程的页框数量；局部置换意味着只能从该进程当前占用的页面中选择一个淘汰。

## 三、逐问解析

### 第（1）问：逻辑地址 17CAH 对应的页号是多少？

#### 1. 考查知识点

逻辑地址划分、页面大小、页号和页内偏移量的计算。

#### 2. 解题思路

逻辑地址由页号和页内偏移量组成：

``` text
逻辑地址 = 页号 × 页面大小 + 页内偏移量
页号 = 逻辑地址 ÷ 页面大小（取整数部分）
页内偏移量 = 逻辑地址对页面大小取余
```

#### 3. 详细计算过程

页面大小：

``` text
1KB = 1024B = 400H
```

将逻辑地址 17CAH 按 400H 划分：

``` text
17CAH = 5 × 400H + 3CAH
```

所以：

-   页号：5
-   页内偏移量：3CAH

#### 4. 最终答案

``` text
页号 = 5
页内偏移量 = 3CAH
```

当前驻留页面只有页 0、页 1、页 2、页 3，页 5
不在内存中，因此访问该地址会发生缺页。

### 第（2）问：采用 FIFO 置换算法，物理地址是多少？

#### 1. 考查知识点

FIFO 页面置换、页面装入时间、局部置换、物理地址计算。

#### 2. 解题思路

FIFO（先进先出）算法的核心思想是：**淘汰最早进入内存的页面。**

判断依据是页面的装入时间，而不是最近访问时间，也不是访问位。

#### 3. 详细计算过程

**（1）确定缺页页面**

第（1）问已经得到：

-   页号：5
-   页内偏移量：3CAH

当前内存中没有页 5，因此发生缺页。

**（2）根据装入时间确定淘汰页面**

将当前页面按照装入时间从早到晚排列：

    页号   页框号   装入时间 FIFO 顺序
  ------ -------- ---------- --------------------
       0        7        130 最早装入，首先淘汰
       3        9        160 第二早
       2        2        200 第三早
       1        4        230 最晚装入

最早装入的是页 0，因此 FIFO 淘汰页 0。

页 0 原来占用页框 7，页 5 调入后使用页框 7：

``` text
页 5 → 页框 7
```

**（3）计算物理地址**

物理地址计算公式：

``` text
物理地址 = 页框号 × 页面大小 + 页内偏移量
```

代入：

``` text
物理地址 = 7 × 400H + 3CAH
         = 1C00H + 3CAH
         = 1FCAH
```

#### 4. 最终答案

``` text
FIFO 对应的物理地址 = 1FCAH
```

原因：FIFO 淘汰最早装入的页 0，释放页框 7，页 5 装入页框
7；页内偏移量仍为 3CAH。

### 第（3）问：采用 CLOCK 置换算法，物理地址是多少？

#### 1. 考查知识点

CLOCK 页面置换、访问位、时钟指针移动、第二次机会机制、物理地址计算。

#### 2. 解题思路

CLOCK（时钟）算法根据访问位决定是否淘汰页面：

-   访问位为
    1：说明页面近期被访问过，给予第二次机会，将访问位清零，指针继续移动。
-   访问位为 0：选择该页面淘汰。

本题四个页面的访问位初始均为 1，指针初始指向页
2，并按题图规定顺时针移动。

#### 3. 详细计算过程

**（1）确定缺页页面**

页号为 5，页内偏移量为 3CAH。页 5 不在内存中，因此发生缺页。

**（2）按照指针起点和方向扫描**

根据题图，指针初始指向页 2，顺时针检查顺序为：

``` text
页 2 → 页 1 → 页 0 → 页 3 → 页 2
```

四个页面的访问位初始均为 1。逐个检查：

    检查次序   当前页面   检查时访问位 操作                     下一步
  ---------- ---------- -------------- ------------------------ ----------
           1       页 2              1 将访问位置为 0，不淘汰   移至页 1
           2       页 1              1 将访问位置为 0，不淘汰   移至页 0
           3       页 0              1 将访问位置为 0，不淘汰   移至页 3
           4       页 3              1 将访问位置为 0，不淘汰   移至页 2
           5       页 2              0 淘汰页 2                 完成置换

第一次扫描四个页面时，所有访问位都由 1 变为 0。指针回到页 2 时，页 2
的访问位已经为 0，因此淘汰页 2。

**（3）确定页 5 使用的页框**

页 2 原来位于页框 2，因此页 5 装入页框 2：

``` text
页 5 → 页框 2
```

**（4）计算物理地址**

``` text
物理地址 = 页框号 × 页面大小 + 页内偏移量
         = 2 × 400H + 3CAH
         = 800H + 3CAH
         = BCAH
```

#### 4. 最终答案

``` text
CLOCK 对应的物理地址 = BCAH
```

原因：指针从页 2 开始顺时针扫描，四个页面的访问位均为
1，第一轮扫描将它们全部清零；回到页 2 时，其访问位为 0，因此淘汰页 2。页
5 装入页框 2，物理地址为 BCAH。

## 四、核心考点总结

### 1. 逻辑地址划分

``` text
逻辑地址 = 页号 × 页面大小 + 页内偏移量
页号 = 逻辑地址 ÷ 页面大小（取整数部分）
页内偏移量 = 逻辑地址对页面大小取余
```

本题页面大小为：

``` text
1KB = 1024B = 400H
17CAH = 5 × 400H + 3CAH
```

所以页号为 5，偏移量为 3CAH。

### 2. 物理地址计算

``` text
物理地址 = 页框号 × 页面大小 + 页内偏移量
```

地址转换时，页内偏移量保持不变，只需将虚拟页号映射为物理页框号。

本题：

-   FIFO：页 5 装入页框 7，物理地址为 `7 × 400H + 3CAH = 1FCAH`。
-   CLOCK：页 5 装入页框 2，物理地址为 `2 × 400H + 3CAH = BCAH`。

### 3. FIFO 页面置换算法

核心思想：**淘汰最早进入内存的页面。**

判断依据是页面装入时间。

本题装入时间顺序：

``` text
页 0（130）→ 页 3（160）→ 页 2（200）→ 页 1（230）
```

因此 FIFO 淘汰页 0。

注意：FIFO 不使用访问位，也不根据最近一次访问时间决定淘汰页面。

### 4. CLOCK 页面置换算法

核心思想：**访问位为 1 的页面获得第二次机会；访问位为 0 的页面被淘汰。**

基本步骤：

1.  检查指针当前指向的页面。
2.  若访问位为 1，将其清零，指针继续移动。
3.  若访问位为 0，淘汰该页面。
4.  新页面装入被淘汰页面原来占用的页框。

本题四个页面访问位均为 1，指针从页 2 开始，顺时针扫描一周后回到页
2。此时页 2 的访问位已被清零，因此淘汰页 2。

### 5. FIFO 与 CLOCK 对比

  对比项目         FIFO             CLOCK
  ---------------- ---------------- -------------------------
  中文名称         先进先出         时钟置换算法
  淘汰依据         装入时间最早     扫描到访问位为 0 的页面
  是否使用访问位   不使用           使用
  管理方式         按装入先后管理   时钟指针循环扫描
  本题淘汰页面     页 0             页 2
  本题使用页框     7                2
  本题物理地址     1FCAH            BCAH

### 6. 固定分配与局部置换

-   **固定分配：** 操作系统为进程分配固定数量的页框。本题分配 4 个。
-   **局部置换：**
    发生缺页时，只能从该进程当前占用的页框中选择页面淘汰。

本题访问页 5 发生缺页时，FIFO 或 CLOCK 都只能在页 0、页 1、页 2、页 3
中选择一个淘汰。

## 五、易错点

### 1. 将 1KB 错误换算成 100H

本题按字节编址，1KB 等于 1024B：

``` text
1024 = 400H
```

不是 100H。页面大小为 400H，页内偏移量必须小于 400H。

### 2. 页号和页内偏移量计算错误

``` text
17CAH = 5 × 400H + 3CAH
```

所以页号是 5，偏移量是 3CAH。不要把十六进制地址按十进制位数直接拆分。

### 3. FIFO 按访问时间而不是装入时间淘汰

FIFO 只看页面进入内存的先后顺序。本题最早装入的是页 0（时刻
130），所以淘汰页 0。访问位全部为 1 对 FIFO 的结果没有影响。

### 4. CLOCK 将访问位为 1 的页面立即淘汰

CLOCK 中，访问位为 1 表示页面获得第二次机会，应先将访问位置为
0，再移动指针；不能直接淘汰。

### 5. CLOCK 忘记题目指定的指针起点和方向

本题指针初始指向页 2，按顺时针方向扫描：

``` text
2 → 1 → 0 → 3 → 2
```

起点和方向会影响扫描过程，不能自行改变。

### 6. 将页框号直接当作物理地址

页框号只是物理页框的编号，物理地址还需要加上页内偏移量：

``` text
物理地址 = 页框号 × 400H + 3CAH
```

### 7. 混淆 FIFO 和 CLOCK 的判断依据

-   FIFO：看谁最早装入内存。
-   CLOCK：看指针扫描到的页面访问位是否为 0。

本题 FIFO 淘汰页 0，CLOCK 淘汰页 2，正是因为两种算法的判断依据不同。
