# 2015 年 408 真题：指令编码、控制信号与执行周期（2015-44）

> 本题是 2015-43 数据通路题的延续。考查 16
> 位指令格式、操作码数量、机器指令编码、控制信号识别，以及单总线 CPU
> 中指令执行所需的时钟周期。
>
> 本题采用题目给出的 2015-43 数据通路：ALU 的 A 输入来自暂存器 T，B
> 输入来自 MUX；ALU 结果进入移位寄存器 SR；SR 经三态门输出到 CPU
> 内部总线。

------------------------------------------------------------------------

## 一、指令格式与已知条件

### 1. 指令格式

题目给出的 16 位指令格式为：

  字段     OP   Md   Rd   Ms1   Rs1   Ms2   Rs2
  ------ ---- ---- ---- ----- ----- ----- -----
  位数      7    1    2     1     2     1     2

总位数：

``` text
7 + 1 + 2 + 1 + 2 + 1 + 2 = 16 位
```

字段排列顺序必须记准确：

``` text
OP | Md | Rd | Ms1 | Rs1 | Ms2 | Rs2
```

### 2. 寻址方式

题目规定：

  ----------------------------------------------------------------------------------------
  寻址方式位              含义                    示例
  ----------------------- ----------------------- ----------------------------------------
  0                       寄存器直接寻址          R1 表示取寄存器 R1 的内容

  1                       寄存器间接寻址          (R1) 表示以 R1
                                                  的内容作为主存地址，访问该地址中的数据
  ----------------------------------------------------------------------------------------

注意：

-   `R1`：直接使用寄存器 R1 中的数据。
-   `(R1)`：先读取 R1 中的内容作为地址，再访问主存，取得该地址处的数据。
-   `((R1))`：本题语义中表示对 R1 所指向的主存单元取值，即
    M\[R1\]，并非再进行第二次间接寻址。

### 3. 寄存器编号

  寄存器   编号
  -------- ------
  R0       00
  R1       01
  R2       10
  R3       11

### 4. 指令地址形式

题目给出的指令语义：

  ------------------------------------------------------------------------------------------------------
  指令类型                指令形式                                含义
  ----------------------- --------------------------------------- --------------------------------------
  三地址指令              `OP 源操作数1 源操作数2 → 目的操作数`   使用两个源操作数，产生一个目的操作数

  二地址指令              `OP 源操作数1 → 目的操作数`             末 3 位为 0

  单地址指令              `OP 目的操作数 → 目的操作数`            末 6 位为 0
  ------------------------------------------------------------------------------------------------------

## 二、第（1）问：该机的指令系统最多可定义多少条指令？

**答案：128 条。**

### 分析

16 位指令中，除 OP 外的字段占用：

``` text
Md + Rd + Ms1 + Rs1 + Ms2 + Rs2
= 1 + 2 + 1 + 2 + 1 + 2
= 9 位
```

因此 OP 字段占用：

``` text
16 - 9 = 7 位
```

7 位操作码最多可以表示：

``` text
2^7 = 128 种
```

所以指令系统最多可以定义 **128 条指令**。

### 易错点

这里问的是操作码可以表示多少种指令，不是问寄存器数量或寻址方式组合数量。

## 三、第（2）问：写出三条指令对应的机器代码

题目给定：

  指令    操作码
  ------- --------
  `inc`   01H
  `shl`   02H
  `sub`   03H

操作码字段 OP 为 7 位，因此：

  操作码   7 位二进制
  -------- ------------
  01H      0000001
  02H      0000010
  03H      0000011

### 1. `inc R1`

指令语义：

``` text
(R1) + 1 → R1
```

这是单地址指令，目的操作数是 R1。

-   OP = 0000001
-   Md = 0：R1 采用寄存器直接寻址
-   Rd = 01：目的寄存器为 R1
-   末 6 位均为 0：Ms1、Rs1、Ms2、Rs2 均为 0

字段拼接：

``` text
OP    Md  Rd  Ms1 Rs1 Ms2 Rs2
0000001 0  01   0  00   0  00
```

完整二进制：

``` text
0000 0010 0100 0000
```

转换为十六进制：

``` text
0240H
```

### 2. `shl R2, R1`

指令语义：

``` text
(R1) << 1 → R2
```

这是二地址指令：

-   源操作数：R1
-   目的操作数：R2
-   末 3 位为 0：Ms2、Rs2 均为 0

字段取值：

-   OP = 0000010
-   Md = 0：目的操作数 R2 为寄存器直接寻址
-   Rd = 10：目的寄存器为 R2
-   Ms1 = 0：源操作数 R1 为寄存器直接寻址
-   Rs1 = 01：源寄存器为 R1
-   Ms2 = 0，Rs2 = 00

字段拼接：

``` text
OP    Md  Rd  Ms1 Rs1 Ms2 Rs2
0000010 0  10   0  01   0  00
```

完整二进制：

``` text
0000 0100 1000 1000
```

转换为十六进制：

``` text
0488H
```

### 3. `sub R3, (R1), R2`

指令语义：

``` text
M[R1] - (R2) → R3
```

这是三地址指令：

-   源操作数 1：`(R1)`，寄存器间接寻址。
-   源操作数 2：`R2`，寄存器直接寻址。
-   目的操作数：`R3`，寄存器直接寻址。

字段取值：

-   OP = 0000011
-   Md = 0：目的操作数 R3 为寄存器直接寻址
-   Rd = 11：目的寄存器为 R3
-   Ms1 = 1：源操作数 1 为寄存器间接寻址
-   Rs1 = 01：源寄存器为 R1
-   Ms2 = 0：源操作数 2 为寄存器直接寻址
-   Rs2 = 10：源寄存器为 R2

字段拼接：

``` text
OP    Md  Rd  Ms1 Rs1 Ms2 Rs2
0000011 0  11   1  01   0  10
```

完整二进制：

``` text
0000 0110 1110 1010
```

转换为十六进制：

``` text
06EAH
```

### 4. 三条指令答案汇总

  指令               机器代码（二进制）      机器代码（十六进制）
  ------------------ ----------------------- ----------------------
  `inc R1`           `0000 0010 0100 0000`   **0240H**
  `shl R2,R1`        `0000 0100 1000 1000`   **0488H**
  `sub R3,(R1),R2`   `0000 0110 1110 1010`   **06EAH**

### 编码题的固定步骤

1.  先写出指令格式各字段的位数和顺序。
2.  判断是单地址、二地址还是三地址指令。
3.  确定目的寄存器、源寄存器。
4.  根据直接或间接寻址确定寻址方式位。
5.  未使用的字段按题目规定补 0。
6.  按字段顺序拼接二进制，最后转换成十六进制。

## 四、第（3）问：确定控制信号 ①～⑧

本问要结合 2015-43 的数据通路图理解。

### 1. 先回顾关键数据通路

``` text
CPU 内部总线 ──→ T ──→ ALU 的 A 输入
       │
       └──→ MUX 输入 1 ──→ ALU 的 B 输入

常数 2 ───────→ MUX 输入 0

ALU 运算结果 ──→ SR ──→ 三态门 ──→ CPU 内部总线
```

控制信号的作用：

  信号    作用
  ------- ---------------------------------
  MUXop   选择 MUX 的数据输入
  ALUop   选择 ALU 执行的运算
  SROp    选择 SR 执行直送、左移或右移
  SRout   控制 SR 是否向 CPU 内部总线输出
  MEMop   控制主存读或写

题目中 MUX 的输入标号为：

-   输入 0：常数 2。
-   输入 1：CPU 内部总线。

所以 MUXop = 0 选择常数 2，MUXop = 1 选择内部总线。

### 2. 取指阶段：确定 ① 和 ②

题目给出的控制信号：

``` text
PCout=1, MARin=1, Tin=1, MEMop=read
MUXop=①, ALUop=add, SROp=②
SRout=1, PCin=1
MDRout=1, IRin=1
```

取指阶段需要完成两个任务：

1.  从主存取出当前指令，送入 IR。
2.  计算下一条指令地址，即 PC + 2。

为什么是 PC + 2？

本题指令长度为 16 位，即 2 字节，主存按字节编址，因此相邻指令地址相差
2。

计算过程：

``` text
PC → T → ALU 的 A 输入
常数 2 → MUX → ALU 的 B 输入

ALU 执行加法：PC + 2
ALU 结果 → SR
SR 直送 → CPU 内部总线
CPU 内部总线 → PC
```

因此：

-   ① MUXop = 0：选择常数 2。
-   ② SROp = mov：SR 直送，不进行移位。

### 3. 执行 `shl R2,R1`：确定 ③ 和 ④

指令语义：

``` text
(R1) << 1 → R2
```

执行过程：

1.  R1 的内容送入 CPU 内部总线，写入 T。
2.  T 中的数据进入 ALU 的 A 输入端。
3.  ALU 直送 A，不进行其他运算。
4.  ALU 结果进入 SR。
5.  SR 执行左移一位。
6.  SR 输出到内部总线，写入 R2。

因此：

-   ③ ALUop = movA：ALU 直送 A。
-   ④ SROp = left：SR 左移一位。

### 4. 执行 `sub R0,R2,(R1)`：确定 ⑤～⑧

指令语义：

``` text
(R2) - M[R1] → R0
```

其中 `(R1)` 是寄存器间接寻址，表示以 R1
的内容作为主存地址，读取该地址中的数据。

执行过程：

1.  R1out = 1，MARin = 1：将 R1 的内容送入 MAR，作为主存地址。
2.  MEMop = read：读取该主存单元的数据，数据进入 MDR。
3.  R2out = 1，Tin = 1：将 R2 的内容暂存到 T。
4.  MDRout = 1：将主存读出的数据送到 CPU 内部总线。
5.  MUXop = 1：选择内部总线数据作为 ALU 的 B 输入。
6.  ALU 执行 T - MDR。
7.  SR 直送运算结果。
8.  SR 输出到内部总线，写入 R0。

因此：

-   ⑤ MEMop = read。
-   ⑥ ALUop = sub。
-   ⑦ SROp = mov。
-   ⑧ SRout = 1。

### 5. 控制信号答案汇总

  标号   控制信号或取值   原因
  ------ ---------------- --------------------------------
  ①      MUXop = 0        选择常数 2，计算 PC+2
  ②      SROp = mov       将 ALU 结果直接送入 SR，不移位
  ③      ALUop = movA     将 ALU 的 A 输入直接送到输出
  ④      SROp = left      对数据左移一位
  ⑤      MEMop = read     读取 R1 所指向的主存单元
  ⑥      ALUop = sub      执行减法
  ⑦      SROp = mov       结果不移位，直接通过 SR
  ⑧      SRout = 1        允许 SR 向内部总线输出

## 五、第（4）问：`sub R1,R3,(R2)` 和 `inc R1` 的执行阶段至少需要多少个时钟周期？

**答案：`sub R1,R3,(R2)` 至少 4 个时钟周期；`inc R1` 至少 3
个时钟周期。**

本问关键是：单总线结构下，同一时刻只能有一路数据驱动内部总线；寄存器需要先接收数据，后续周期才能使用新数据。

### 1. `sub R1,R3,(R2)`

指令语义：

``` text
(R3) - M[R2] → R1
```

需要完成：

-   通过 R2 得到主存地址。
-   从主存读取 M\[R2\]。
-   将 R3 暂存到 T。
-   ALU 执行 R3 - M\[R2\]。
-   将结果写回 R1。

#### 第 1 个时钟周期：访问主存地址

``` text
R2out = 1
MARin = 1
MEMop = read
```

数据流：

``` text
R2 → CPU 内部总线 → MAR
```

将 R2 的内容作为主存地址，启动读操作。

#### 第 2 个时钟周期：暂存 R3

``` text
R3out = 1
Tin = 1
```

数据流：

``` text
R3 → CPU 内部总线 → T
```

在主存读取数据的同时，利用 CPU 内部总线将 R3 保存到 T。R2 和 R3
不能在同一时钟周期同时驱动单总线，因此必须分开。

#### 第 3 个时钟周期：执行减法

``` text
MDRout = 1
MUXop = 1
ALUop = sub
SROp = mov
```

数据流：

``` text
T 中的 R3 → ALU 的 A 输入
MDR 中的 M[R2] → 内部总线 → MUX → ALU 的 B 输入

ALU：R3 - M[R2]
ALU 结果 → SR
```

#### 第 4 个时钟周期：写回结果

``` text
SRout = 1
R1in = 1
```

数据流：

``` text
SR → CPU 内部总线 → R1
```

所以：

``` text
sub R1,R3,(R2)：至少 4 个时钟周期
```

### 2. `inc R1`

指令语义：

``` text
(R1) + 1 → R1
```

ALU 支持 A+1（inc）操作，但 ALU 的 A 输入来自 T，因此仍然需要先将 R1
保存到 T。

#### 第 1 个时钟周期：暂存 R1

``` text
R1out = 1
Tin = 1
```

数据流：

``` text
R1 → CPU 内部总线 → T
```

#### 第 2 个时钟周期：执行加 1

``` text
ALUop = inc
SROp = mov
```

数据流：

``` text
T → ALU
ALU：T + 1
ALU 结果 → SR
```

#### 第 3 个时钟周期：写回 R1

``` text
SRout = 1
R1in = 1
```

数据流：

``` text
SR → CPU 内部总线 → R1
```

所以：

``` text
inc R1：至少 3 个时钟周期
```

### 3. 周期数汇总

  ---------------------------------------------------------------------------------------------------------------
  指令               第 1 周期            第 2 周期             第 3 周期              第 4 周期       最少周期数
  ------------------ -------------------- --------------------- ---------------------- ----------- --------------
  `sub R1,R3,(R2)`   R2→MAR，启动读主存   R3→T                  MDR参与减法，结果→SR   SR→R1                **4**

  `inc R1`           R1→T                 ALU执行T+1，结果→SR   SR→R1                  ---                  **3**
  ---------------------------------------------------------------------------------------------------------------

### 4. 为什么不能再减少周期？

主要有三个原因：

1.  **单总线限制：** R2 和 R3 都需要通过 CPU
    内部总线传送，不能在同一周期同时驱动总线。
2.  **暂存器限制：** 必须先把操作数写入 T，下一周期才能使用 T
    中保存的数据完成 ALU 运算。
3.  **结果写回限制：** ALU 结果先进入 SR，之后才能通过 SRout
    输出到总线，再写入目的寄存器。

因此，按照题目给出的单总线数据通路和寄存器传送时序，两个指令的最少执行周期分别为
4 和 3。

## 七、408 考前重点记忆

### 1. 指令编码

-   先根据指令格式确定各字段位数。
-   直接寻址位为 0，间接寻址位为 1。
-   目的寄存器写入 Rd，源寄存器写入 Rs1、Rs2。
-   未使用字段按题目要求补 0。
-   OP 字段有 7 位，因此最多表示 128 种操作码。

### 2. 控制信号

-   MUXop：决定选择哪一路数据。
-   ALUop：决定 ALU 执行什么运算。
-   SROp：决定 SR 直送、左移或右移。
-   SRout：决定 SR 是否向总线输出。
-   MEMop：决定主存执行读还是写。

### 3. 单总线执行周期

分析执行周期时，按以下顺序检查：

1.  操作数从哪里来？
2.  是否需要先通过总线送入暂存器 T？
3.  是否需要访问主存？
4.  ALU 何时能够得到两个操作数？
5.  运算结果是否需要经过 SR？
6.  结果何时能够写回目的寄存器？

**本题最重要的结果：指令系统最多 128 条；三条机器代码分别为
0240H、0488H、06EAH；两个指令执行阶段分别至少需要 4 和 3 个时钟周期。**
