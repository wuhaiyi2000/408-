# 2015-43 2015 年 408 真题：CPU 数据通路与控制信号（2015-43）

> 本题考查单总线结构、程序员可见寄存器、暂存器、多路选择器（MUX）、ALU
> 控制信号、三态门，以及数据通路的补线方法。

## 一、题目背景与部件说明

题目给出的计算机具有以下特点：

-   主存按字节编址，存取单位为 16 位。
-   采用 16 位定长指令字格式。
-   CPU 采用单总线结构。
-   R0～R3 为通用寄存器。
-   T 为暂存器。
-   SR
    为移位寄存器，可以实现直送（mov）、左移一位（left）和右移一位（right）。
-   SR 的输出由 SRout 控制。
-   ALU 可以实现 7 种操作：直送 A（movA）、A 加 B（add）、A 减
    B（sub）、A 与 B（and）、A 或 B（or）、非 A（not）、A 加 1（inc）。

### 1. 图中主要部件分类

  类别               部件         主要作用
  ------------------ ------------ ------------------------------------
  程序员可见寄存器   R0～R3、PC   存放程序运行所需的数据和地址
  CPU 内部寄存器     T            暂存操作数
  CPU 内部寄存器     SR           暂存 ALU 运算结果并进行移位
  CPU 内部寄存器     MAR          存放主存地址
  CPU 内部寄存器     MDR          存放从主存读出或准备写入主存的数据
  CPU 内部寄存器     IR           存放当前指令
  选择部件           MUX          从多个数据输入中选择一路输出
  控制部件           控制器       产生各部件所需的控制信号

### 2. 数据通路的基本关系

本题中，ALU 的两个操作数来源不同：

-   ALU 的 A 输入来自暂存器 T。
-   ALU 的 B 输入来自 MUX 的输出。
-   MUX 的一个数据输入为常数 2，另一个数据输入来自 CPU 内部总线。
-   ALU 的运算结果送入移位寄存器 SR。
-   SR 的输出经过受 SRout 控制的三态门，送回 CPU 内部总线。

可以把主要数据流记成：

``` text
CPU 内部总线 ──→ T ──→ ALU 的 A 输入
       │
       └──→ MUX 输入 1 ──→ ALU 的 B 输入

常数 2 ───────→ MUX 输入 0

ALU 运算结果 ──→ SR ──→ 三态门 ──→ CPU 内部总线
```

## 二、第（1）问：哪些寄存器是程序员可见的？为什么设置暂存器 T？

### 1. 程序员可见的寄存器

**答案：R0～R3、PC。**

-   R0～R3：通用寄存器，可以用于存放操作数和运算结果。
-   PC：程序计数器，存放下一条待执行指令的地址，控制程序执行顺序。

其他寄存器属于 CPU 内部使用的寄存器：

  寄存器   程序员可见？   作用
  -------- -------------- ----------------------------
  R0～R3   是             通用寄存器
  PC       是             存放下一条待执行指令的地址
  T        否             暂存操作数
  SR       否             暂存运算结果并进行移位
  MAR      否             存放主存地址
  MDR      否             存放主存读写数据
  IR       否             存放当前指令

### 2. 为什么需要设置 T？

因为 CPU 采用**单总线结构**，同一时刻总线上只能传送一路数据。

例如，要执行：

``` text
R0 = R1 + R2
```

ALU 需要同时获得两个操作数：R1 和
R2。但单总线一次只能传送一个操作数，因此需要暂存器 T
暂存其中一个操作数。

执行过程可以理解为：

1.  将 R1 的内容送到 CPU 内部总线，再写入 T。
2.  将 R2 的内容送到 CPU 内部总线，并经 MUX 送到 ALU 的 B 输入端。
3.  T 的内容送到 ALU 的 A 输入端。
4.  ALU 执行加法，结果送入 SR。
5.  SR 的结果经三态门送回 CPU 内部总线，再写入目标寄存器 R0。

``` text
R1 → 内部总线 → T ─────────→ ALU 的 A 输入
                                  │
R2 → 内部总线 → MUX → ALU 的 B 输入
                                  │
                                  ↓
                              ALU 执行加法
                                  ↓
                                  SR
                                  ↓
                              内部总线
                                  ↓
                                  R0
```

**结论：T
的作用是暂存一个操作数，使单总线结构也能够完成需要两个操作数的运算。**

## 三、第（2）问：控制信号 ALUop 和 SROp 至少需要多少位？

控制信号需要能够区分部件支持的全部操作。

### 1. ALUop

题目说明 ALU 可以实现 7 种操作：

1.  直送 A（movA）
2.  A 加 B（add）
3.  A 减 B（sub）
4.  A 与 B（and）
5.  A 或 B（or）
6.  非 A（not）
7.  A 加 1（inc）

需要区分 7 种状态：

-   2 位最多表示 4 种状态，不够。
-   3 位最多表示 8 种状态，足够。

因此：

**ALUop 至少需要 3 位。**

### 2. SROp

SR 可以实现 3 种操作：

1.  直送（mov）
2.  左移一位（left）
3.  右移一位（right）

需要区分 3 种状态：

-   1 位最多表示 2 种状态，不够。
-   2 位最多表示 4 种状态，足够。

因此：

**SROp 至少需要 2 位。**

### 3. 通用计算方法

若一个部件有 N 种需要区分的操作，控制信号至少需要的位数为：

``` text
最少控制位数 = 向上取整(log₂N)
```

    操作数量   最少控制位数
  ---------- --------------
           2           1 位
        3～4           2 位
        5～8           3 位
       9～16           4 位

## 四、第（3）问：SRout 控制的部件名称或作用是什么？

**答案：三态门（或三态缓冲器）。**

图中 SR 的输出不是直接连接到 CPU 内部总线，而是经过一个受 SRout
控制的三态门。

### 1. 为什么需要三态门？

CPU
采用单总线结构。多个部件可能都连接到同一条总线上，但同一时刻不能让多个部件同时驱动总线，否则可能发生总线冲突。

三态门具有三种输出状态：

-   逻辑 0
-   逻辑 1
-   高阻态 Z

当三态门处于高阻态时，相当于该部件与总线断开，不向总线输出数据。

### 2. SRout 的作用

SRout 控制 SR 是否将自身的数据输出到 CPU 内部总线：

-   SRout 有效：允许 SR 的内容经过三态门输出到总线。
-   SRout 无效：SR 的输出端处于高阻态，不驱动总线。

### 3. SRout 与 SROp 的区别

  控制信号   控制对象            作用
  ---------- ------------------- --------------------------------
  SROp       移位寄存器 SR       决定 SR 执行直送、左移还是右移
  SRout      SR 输出端的三态门   决定 SR 是否向内部总线输出数据

**记忆：SROp 管 SR 做什么；SRout 管 SR 是否把数据送上总线。**

## 五、第（4）问：端点 ①～⑨中，哪些端点需要连接控制部件的输出端？

**答案：①、②、③、⑤、⑧。**

判断原则：

-   控制信号端口连接控制部件。
-   数据输入端、数据输出端连接数据通路，而不是连接控制部件。

  端点   对应信号或部件    端口类型       是否连接控制部件
  ------ ----------------- -------------- ------------------
  ①      SRout             控制信号输入   是
  ②      SROp              控制信号输入   是
  ③      ALUop             控制信号输入   是
  ④      ALU 的 B 输入端   数据输入       否
  ⑤      Tin               控制信号输入   是
  ⑥      CPU 内部总线      数据通路       否
  ⑦      MUX 输出端        数据输出       否
  ⑧      MUX 选择控制端    控制信号输入   是
  ⑨      MUX 的输入 1      数据输入       否

因此，需要连接控制部件输出端的端点为：

``` text
①、②、③、⑤、⑧
```

**易错点：MUX 的选择控制端需要连接控制部件，但 MUX
的数据输入端和输出端属于数据通路。**

## 六、第（5）问：需要在哪些端点之间添加连线？

**答案：④与⑦连接；⑥与⑨连接。**

本问的任务是补全数据通路。

### 1. 端点 ④ 与端点 ⑦连接

-   ④：ALU 的 B 输入端。
-   ⑦：MUX 的输出端。

MUX 从输入端选择一路数据后，将数据送到 ALU 的 B 输入端。

因此连接方向为：

``` text
MUX 输出端（⑦）→ ALU 的 B 输入端（④）
```

### 2. 端点 ⑥ 与端点 ⑨连接

-   ⑥：CPU 内部总线。
-   ⑨：MUX 的输入 1。

MUX 有两个数据输入：

  MUX 输入   数据来源
  ---------- --------------
  输入 0     常数 2
  输入 1     CPU 内部总线

因此连接方向为：

``` text
CPU 内部总线（⑥）→ MUX 输入 1（⑨）
```

### 3. 补线结果汇总

  连接端点   数据流方向                  作用
  ---------- --------------------------- ---------------------------
  ⑦ → ④      MUX 输出 → ALU 的 B 输入    将选中的数据送入 ALU
  ⑥ → ⑨      CPU 内部总线 → MUX 输入 1   使 MUX 能选择内部总线数据

## 七、第（6）问：为什么 MUX 的一个输入端是 2？

**答案：用于实现 PC 加 2。**

题目给出：

-   主存按字节编址。
-   存取单位为 16 位。
-   指令采用 16 位定长格式。

### 1. 一条指令占多少字节？

16 位 = 2 字节。

由于主存按字节编址，相邻两个字节的地址相差 1。因此，一条 16
位指令占用两个字节，相邻指令的起始地址相差 2。

例如：

  指令           起始地址
  ------------ ----------
  第一条指令          100
  第二条指令          102
  第三条指令          104
  第四条指令          106

所以，顺序执行时 PC 应增加 2：

``` text
PC = PC + 2
```

### 2. 为什么 MUX 需要提供常数 2？

ALU 可以执行 A+B（add），因此可以将：

-   ALU 的 A 输入设置为 PC。
-   ALU 的 B 输入设置为常数 2。

ALU 执行加法后得到：

``` text
PC + 2
```

MUX 的两个数据输入分别是：

-   输入 0：常数 2。
-   输入 1：CPU 内部总线。

控制部件可以根据当前操作选择合适的数据来源。

**注意：这里的 2 表示 2 字节，不是 2 个 16 位字。**

## 九、408 考前重点记忆

### 1. 单总线结构

-   同一时刻总线上只能传送一路数据。
-   双操作数运算时，需要暂存器 T 暂存一个操作数。
-   暂存器 T 是 CPU 内部寄存器，不属于程序员可见寄存器。

### 2. 多路选择器 MUX

-   多路数据输入，一路数据输出。
-   选择控制端由控制部件提供控制信号。
-   数据输入端和输出端属于数据通路。
-   选择信号决定哪一路数据被送到输出端。

### 3. 控制信号位数

-   N 种操作至少需要向上取整(log₂N)位控制信号。
-   ALU 有 7 种操作，至少需要 3 位。
-   SR 有 3 种操作，至少需要 2 位。

### 4. 三态门

-   三种状态：0、1、高阻态 Z。
-   控制寄存器是否向总线输出。
-   避免多个部件同时驱动总线而发生冲突。

### 5. PC 增量

-   按字节编址时，PC 的顺序增量取决于指令占用的字节数。
-   本题指令长度为 16 位，即 2 字节。
-   因此顺序执行时 PC 增加 2。

### 6. 数据通路补线题的判断方法

1.  先识别端点属于控制信号还是数据通路。
2.  控制信号端口连接控制部件。
3.  数据输入端、数据输出端根据数据流向连接。
4.  MUX 的选择端接控制信号，数据端接数据通路。
5.  三态门控制输出是否接入总线。

**本题最重要的结论：单总线需要 T 暂存操作数；SRout 控制三态门；MUX
的选择端接控制器；本题补线为 ⑦→④、⑥→⑨；MUX 提供常数 2 是为了实现
PC+2。**
