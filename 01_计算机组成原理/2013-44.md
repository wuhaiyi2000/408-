# 2013-44：条件转移指令、标志寄存器与数据通路

## 一、题目考点

**一级考点：条件转移指令的执行与地址计算**

主要涉及：

1. 存储器编址方式
2. 补码与相对寻址
3. CF、ZF、NF标志位
4. 无符号数比较
5. 条件转移指令的数据通路
6. 移位器、加法器、多路选择器

---

## 二、题目已知条件

某计算机采用16位定长指令字格式，CPU中有一个标志寄存器，包含三个标志位：

| 标志位 | 含义 |
|---|---|
| CF | 进位标志 |
| ZF | 零标志 |
| NF | 符号标志 |

条件转移指令格式：

| 位数 | 字段 | 含义 |
|---|---|---|
| 15～11 | OP | 操作码，固定00000 |
| 10 | C | 是否检测CF |
| 9 | Z | 是否检测ZF |
| 8 | N | 是否检测NF |
| 7～0 | OFFSET | 8位补码偏移量 |

### 条件转移规则

- C=1：检测CF。
- Z=1：检测ZF。
- N=1：检测NF。
- 被选中的标志位中，只要有一个为1，就发生转移。
- 如果所有被选中的标志位均为0，则顺序执行。

转移地址公式：

`目标地址 = PC + 2 + 2 × OFFSET`

顺序执行地址：

`PC = PC + 2`

注意：PC表示当前条件转移指令的地址。

## 三、第（1）问：判断编址方式及最大反向转移范围

### 1. 判断编址方式

已知：

- 指令字长为16位。
- 16位 = 2B。
- 顺序执行时，下一条指令地址为PC+2。

说明相邻指令地址相差2。

因此，计算机采用按字节编址。

### 2. 计算最大反向转移范围

OFFSET占8位，采用补码表示。

8位补码范围：

`-128 ～ +127`

最大反向转移取最小值：

`OFFSET = -128`

代入转移地址公式：

`目标地址 = PC + 2 + 2 × (-128)`

`= PC + 2 - 256`

`= PC - 254`

以PC+2为基准，最大反向偏移距离：

`256B / 2B = 128条指令`

### 最终答案

- 编址方式：按字节编址。
- OFFSET范围：-128～127。
- 最大反向转移距离：128条指令（以PC+2为基准）。

## 四、第（2）问：计算条件转移后的PC值

已知：

- 条件转移指令地址：200CH。
- C=0，Z=1，N=1。
- OFFSET=11100011B。

### 1. 计算OFFSET

OFFSET为8位补码：

`11100011B = E3H`

最高位为1，说明是负数。

求补码对应的绝对值：

第一步：按位取反。

`11100011 → 00011100`

第二步：加1。

`00011100 + 1 = 00011101`

`00011101B = 29`

因此：

`OFFSET = -29`

### 2. 计算顺序执行地址

当前PC：

`PC = 200CH`

顺序执行地址：

`PC + 2 = 200EH`

### 3. 情况一：CF=0，ZF=0，NF=1

指令控制位：

- C=0：不检测CF。
- Z=1：检测ZF。
- N=1：检测NF。

| 标志位 | 是否检测 | 实际值 | 是否满足转移 |
|---|---|---|---|
| CF | 否 | 0 | 忽略 |
| ZF | 是 | 0 | 否 |
| NF | 是 | 1 | 是 |

因为NF=1，所以发生转移。

计算：

`PC = 200CH + 2 + 2 × (-29)`

`= 200EH - 58（十进制）`

`= 200EH - 3AH`

`= 1FD4H`

**答案：PC=1FD4H。**

### 4. 情况二：CF=1，ZF=0，NF=0

| 标志位 | 是否检测 | 实际值 | 是否满足转移 |
|---|---|---|---|
| CF | 否 | 1 | 忽略 |
| ZF | 是 | 0 | 否 |
| NF | 是 | 0 | 否 |

虽然CF=1，但是C=0，因此不检测CF。

ZF和NF均为0，不发生转移。

顺序执行：

`PC = 200CH + 2`

`PC = 200EH`

**答案：PC=200EH。**

### 易错点

不能看到某个标志位为1，就直接判断发生转移。

必须先看指令中的C、Z、N是否要求检测对应标志位。

## 五、第（3）问：实现无符号数A小于等于B时转移

题目要求实现：

`A <= B 时转移`

通过减法：

`A - B`

利用CF和ZF判断。

### 1. A小于B

无符号减法发生借位：

`CF = 1`

因此发生转移。

### 2. A等于B

减法结果为0：

`ZF = 1`

因此发生转移。

### 3. A大于B

既不发生借位，结果也不为0：

`CF = 0，ZF = 0`

不发生转移。

### 4. 设置C、Z、N

| 比较结果 | CF | ZF | 是否转移 |
|---|---:|---:|---|
| A小于B | 1 | 0 | 是 |
| A等于B | 0 | 1 | 是 |
| A大于B | 0 | 0 | 否 |

因此，需要检测CF和ZF，不需要检测NF。

**最终答案：**

`C=1，Z=1，N=0`

### 易错点

无符号数比较不能单独看NF。

例如，8位无符号数：

`A=0，B=200`

计算：

`A-B=-200`

8位运算结果为：

`256-200=56`

56的二进制为：

`00111000`

最高位为0，但实际上A仍然小于B。

因此，无符号数比较主要看CF（借位标志）和ZF（零标志）。

注意：本题按CF=1表示减法发生借位的约定进行判断。

## 六、第（4）问：条件转移指令的数据通路

### 1. 三个空格的名称

| 编号 | 名称 | 功能 |
|---|---|---|
| ① | 指令寄存器IR | 保存当前条件转移指令 |
| ② | 左移1位器 | OFFSET左移1位，相当于乘以2 |
| ③ | 加法器 | 计算最终转移目标地址 |

### 2. ①：指令寄存器IR

指令寄存器用于保存当前执行的条件转移指令。

指令中包含：

- OP：操作码。
- C：是否检测CF。
- Z：是否检测ZF。
- N：是否检测NF。
- OFFSET：偏移量。

这些字段分别送往对应的控制逻辑和地址计算电路。

### 3. ②：左移1位器

目标地址计算公式：

`目标地址 = PC + 2 + 2 × OFFSET`

其中：

`2 × OFFSET = OFFSET左移1位`

因此，②是左移1位器。

注意：

**移位器和加法器是两个不同的硬件部件。**

- 移位器：负责左移或右移。
- 加法器：负责两个数相加。

OFFSET在移位前需要进行符号扩展，保证负数的符号正确。

### 4. ③：加法器

数据通路中：

- 第一个加法器计算PC+2。
- OFFSET经过符号扩展。
- ②将OFFSET左移1位。
- ③将PC+2与处理后的OFFSET相加。

因此③是加法器。

计算结果：

`目标地址 = (PC+2) + (OFFSET×2)`

### 5. 左侧逻辑电路的功能

标志寄存器提供：

- CF
- ZF
- NF

指令寄存器提供：

- C
- Z
- N

分别进行与运算：

`C AND CF`

`Z AND ZF`

`N AND NF`

然后将三个结果进行或运算：

`转移条件 = (C AND CF) OR (Z AND ZF) OR (N AND NF)`

结果为1：发生转移。

结果为0：顺序执行。

### 6. 多路选择器的功能

多路选择器根据转移条件决定PC的下一个值。

| 转移条件 | 多路选择器选择 | PC更新 |
|---|---|---|
| 满足转移 | 转移目标地址 | PC+2+2×OFFSET |
| 不满足转移 | 顺序地址 | PC+2 |

## 八、考点速记

1. 16位指令占2B，相邻指令地址相差2，按字节编址。
2. 8位补码范围：-128～127。
3. 相对转移地址：PC+指令长度+OFFSET×指令长度。
4. 条件转移：先判断检测位，再判断对应标志位。
5. 无符号数A小于等于B：减法时检测借位CF和零标志ZF。
6. 移位器负责移位，加法器负责加法。
7. 多路选择器负责选择顺序执行地址或转移目标地址。

### 本题核心公式

转移目标地址：

`目标地址 = PC + 2 + 2 × OFFSET`

转移条件：

`(C AND CF) OR (Z AND ZF) OR (N AND NF)`

无符号数A小于等于B：

`CF OR ZF = 1`
