## 二、第（1）问：求 A～G 的位数

### 1. 求页面内偏移量

页面大小为 8 KB：

``` text
8 KB = 8 × 1024 B
     = 8192 B
     = 2^13 B
```

按字节编址，因此页面内偏移量需要 13 位。

``` text
页面内偏移量 = 13 位
```

### 2. 求虚页号和物理页框号

虚拟地址共 32 位：

``` text
虚页号位数 = 32 - 13 = 19 位
```

物理地址共 24 位：

``` text
物理页框号位数 = 24 - 13 = 11 位
```

因此：

-   虚拟地址 = 虚页号 + 页面内偏移量 = 19 位 + 13 位。
-   物理地址 = 物理页框号 + 页面内偏移量 = 11 位 + 13 位。

### 3. A、B、C、D 字段

  字段   含义                          位数
  ------ -------------------------- -------
  A      虚拟地址中的虚页号           19 位
  B      TLB 标记字段，保存虚页号     19 位
  C      物理地址中的物理页框号       11 位
  D      页面内偏移量                 13 位

**为什么 B 保存虚页号？**

TLB 用来缓存"虚页号 → 物理页框号"的地址转换关系。

访问 TLB 时，CPU 将当前虚拟地址中的虚页号与 TLB 各表项的标记字段比较：

-   匹配：TLB 命中，直接得到物理页框号。
-   不匹配：TLB 缺失，需要查询页表。

本题 TLB 采用全相联映射，因此虚页号可以与 TLB
中所有表项的标记字段进行比较，不需要用虚页号划分 TLB 组号。

题目没有给出 ASID 等进程标识字段，因此按题目模型，B 保存虚页号即可。

### 4. 求 Cache 的地址字段 E、F、G

已知：

-   Cache 数据区容量：64 KB。
-   主存块大小：64 B。
-   Cache：2 路组相联。
-   物理地址：24 位。

**第一步：求 Cache 总行数。**

``` text
Cache 总行数 = Cache 数据区容量 ÷ 主存块大小
             = 64 KB ÷ 64 B
             = 65536 B ÷ 64 B
             = 1024 行
```

**第二步：求 Cache 组数。**

2 路组相联表示每组有 2 行：

``` text
Cache 组数 = Cache 总行数 ÷ 路数
           = 1024 ÷ 2
           = 512 组
           = 2^9 组
```

因此，组索引需要 9 位。

**第三步：求块内地址 G。**

主存块大小为 64 B：

``` text
块内地址位数 = log2(64) = 6 位
```

因此 G 为 6 位。

**第四步：求 Cache 标记 E。**

物理地址共 24 位：

``` text
Cache 标记位数
= 物理地址位数 - 组索引位数 - 块内地址位数
= 24 - 9 - 6
= 9 位
```

因此 E 为 9 位。

### 5. A～G 最终答案

  字段   含义                        位数
  ------ -------------------- -----------
  A      虚页号                 **19 位**
  B      TLB 标记，即虚页号     **19 位**
  C      物理页框号             **11 位**
  D      页面内偏移量           **13 位**
  E      Cache 标记              **9 位**
  F      Cache 组索引            **9 位**
  G      Cache 块内地址          **6 位**

物理地址用于 Cache 访问时，可以划分为：

``` text
物理地址（24 位）：

┌──────────────┬──────────────┬──────────────┐
│ Cache 标记 E │ 组索引 F     │ 块内地址 G  │
│    9 位      │    9 位      │    6 位      │
└──────────────┴──────────────┴──────────────┘
```

注意：页面内偏移量 D 是 13 位，而 Cache 的组索引 F 与块内地址 G 合计 15
位。由于 Cache 按物理地址划分标记、组索引和块内地址，F
的部分位可以来自物理页框号 C，不能误认为 F 和 G 必须全部包含在 D 中。

## 三、第（2）问：主存块号 4099 映射到哪个 Cache 组？H 是什么？

已知：

-   Cache 数据区容量：64 KB。
-   主存块大小：64 B。
-   2 路组相联。
-   前面已经求出 Cache 共 512 组。

### 1. 求 Cache 组号

二路组相联 Cache 的组号计算：

``` text
Cache 组号 = 主存块号 mod Cache 组数
```

代入：

``` text
4099 mod 512 = 3
```

所以主存块号 4099 映射到：

**Cache 第 3 组。**

注意：这里按从 0 开始编号，因此组号为 3；如果题目采用从 1
开始的自然数描述，才会称为第 4 组。408 地址映射题通常使用从 0
开始的组号。

### 2. 求 H 字段内容

H 位于 Cache 的标记字段，因此 H 保存该主存块对应的 Cache 标记。

计算：

``` text
Cache 标记 = 主存块号 ÷ Cache 组数（取整数部分）

           = 4099 ÷ 512

           = 8
```

所以：

``` text
H = 8
```

H 字段宽度为 9 位，因此二进制表示为：

``` text
000001000
```

### 3. 为什么要同时计算组号和标记？

二路组相联 Cache 中：

-   组号：确定主存块应该进入 Cache 的哪一组。
-   标记：区分映射到同一组的不同主存块。
-   块内地址：确定读取该 Cache 块中的哪个字节。

本题：

  项目                             结果
  --------------------- ---------------
  主存块号                         4099
  Cache 组数                        512
  Cache 组号                      **3**
  Cache 标记 H                    **8**
  H 的 9 位二进制表示     **000001000**

同一个 Cache 组中有 2 个 Cache 行，因此该主存块可以装入第 3
组中的任意一路，具体装入哪一路取决于替换策略和当前 Cache
状态。题目没有要求确定具体哪一路。

## 四、第（3）问：Cache 缺失处理与缺页处理，哪个时间开销更大？

**答案：缺页处理的时间开销更大。**

### 1. Cache 缺失（Cache Miss）

CPU 访问 Cache 时，如果没有找到所需数据，就发生 Cache 缺失。

处理过程通常包括：

1.  访问主存。
2.  将所需主存块调入 Cache。
3.  将数据提供给 CPU。
4.  必要时替换 Cache 中原有的数据块。

Cache 缺失通常需要访问主存。虽然比 Cache
命中慢，但主存仍然是半导体存储器，访问速度相对较快。

### 2. 缺页（Page Fault）

CPU 访问某个虚拟页面时，如果该页面不在物理内存中，就会发生缺页异常。

处理过程通常包括：

1.  CPU 触发缺页异常，转入操作系统。
2.  操作系统检查访问是否合法。
3.  为该页面分配物理页框；必要时选择一个页面进行置换。
4.  如果被置换页面已修改，需要先将其写回外存。
5.  从磁盘等外存将所需页面调入内存。
6.  更新页表等相关信息。
7.  重新执行引发缺页的指令。

缺页处理可能涉及磁盘
I/O。磁盘访问时间远大于主存访问时间，而且还需要操作系统进行异常处理和页面调度。

### 3. 两者对比

  对比项目               Cache 缺失             缺页
  ---------------------- ---------------------- --------------------
  发生位置               Cache                  虚拟存储管理
  处理主体               硬件为主               操作系统参与
  数据来源               通常从主存调入 Cache   通常从外存调入内存
  是否可能涉及磁盘 I/O   通常不涉及             可能涉及
  时间开销               较小                   很大

**结论：缺页处理的时间开销远大于 Cache 缺失处理。**

记忆：Cache 缺失主要是主存与 Cache
之间的数据调动；缺页可能需要磁盘与内存之间的数据调动。

## 五、第（4）问：为什么 Cache 可以采用写直达，而页面修改总是采用写回？

这道题考查不同存储层次的速度差异，以及写策略的选择。

### 1. Cache 的写直达（Write Through）

写直达的含义：

当 CPU 修改 Cache 中的数据时，同时将修改写入主存。

``` text
CPU 写数据
    │
    ▼
  Cache
    │
    ├──────────► 主存
    │
    └── Cache 中的数据也被更新
```

特点：

-   Cache 和主存中的数据能够保持一致。
-   不需要等到 Cache 块被替换时才写回主存。
-   写操作会产生额外的主存访问，可能降低写入速度。
-   可以配合写缓冲区（Write Buffer）缓解速度差异。

为什么 Cache 可以采用写直达？

因为 Cache
与主存之间的速度差距虽然明显，但主存仍然是半导体存储器，写入主存的时间开销相对于磁盘
I/O 小得多。采用写直达可以简化一致性维护。

注意：Cache
并非只能使用写直达，也可以使用写回策略，具体取决于体系结构设计。

### 2. 页面修改采用写回（Write Back）

虚拟存储中，页面通常位于主存，外存（例如磁盘）保存页面的后备副本。

写回策略的含义：

CPU
修改内存中的页面时，先只修改主存中的页面，并将该页的修改位（脏位、Dirty
Bit）置为 1。

只有当该页面需要被置换出去时，才检查脏位：

-   脏位为 0：页面未修改，可以直接丢弃，不需要写回外存。
-   脏位为 1：页面已修改，需要先写回外存，再调入新页面。

``` text
CPU 修改页面
     │
     ▼
修改主存中的页面
     │
     ▼
将页面脏位置为 1
     │
     ▼
页面被置换时检查脏位
     │
     ├── 脏位 = 0：直接置换
     │
     └── 脏位 = 1：先写回外存，再置换
```

### 3. 为什么页面修改不能采用写直达？

因为主存与磁盘之间的速度差距非常大。

如果每次修改内存页面中的一个数据，都立即将修改写入磁盘：

-   会产生大量磁盘 I/O。
-   磁盘访问速度远低于主存。
-   程序执行效率会严重下降。

因此，虚拟存储采用写回策略：先在主存中修改页面，等页面被置换时，再将修改过的页面写回外存。

### 4. 两种策略对比

  对比项目               Cache 写直达                        页面写回
  ---------------------- ----------------------------------- ----------------------
  修改数据时             同时更新 Cache 和主存               先修改主存页面
  是否立即更新后备存储   是，写入主存                        否，延迟到页面置换时
  主要目的               简化 Cache 与主存的数据一致性维护   减少昂贵的磁盘 I/O
  典型辅助机制           写缓冲区                            页面修改位（脏位）

**核心原因：主存与 Cache
的速度差距，相比主存与磁盘的速度差距要小得多。**

所以，Cache
可以选择写直达；而虚拟存储中的页面修改通常采用写回，以避免频繁访问磁盘。

## 七、408 考前速记

### 1. 页式虚拟存储地址划分

``` text
页面大小 = 2^n B
页面内偏移量 = n 位

虚页号位数 = 虚拟地址位数 - n

物理页框号位数 = 物理地址位数 - n
```

### 2. TLB

-   TLB 是页表项的高速缓存。
-   保存虚页号到物理页框号的映射。
-   全相联 TLB：虚页号与所有 TLB 表项的标记比较。
-   TLB 命中：直接获得物理页框号。
-   TLB 缺失：需要查询页表。

### 3. 组相联 Cache

``` text
Cache 总行数 = Cache 数据区容量 ÷ 主存块大小

Cache 组数 = Cache 总行数 ÷ 路数

块内地址位数 = log2(主存块大小)

组索引位数 = log2(Cache 组数)

Cache 标记位数
= 物理地址位数 - 组索引位数 - 块内地址位数
```

主存块号映射：

``` text
Cache 组号 = 主存块号 mod Cache 组数

Cache 标记 = 主存块号 ÷ Cache 组数（取整数部分）
```

### 4. Cache 缺失与缺页

-   Cache 缺失：通常从主存调入 Cache。
-   缺页：可能从磁盘调入主存，需要操作系统参与。
-   缺页处理的时间开销通常远大于 Cache 缺失。

### 5. 写策略

-   写直达（Write Through）：修改 Cache 时同步写主存。
-   写回（Write Back）：先修改当前层，置脏位，替换时再写回后备存储。
-   页面写回：利用脏位判断页面是否需要写回磁盘。

**本题最重要的计算链：**

``` text
8 KB 页面 → 页面偏移 13 位

32 位虚拟地址 → 虚页号 19 位

24 位物理地址 → 页框号 11 位

64 KB Cache / 64 B 块 → 1024 行

1024 行 / 2 路 → 512 组

512 组 → 组索引 9 位

64 B 块 → 块内地址 6 位

Cache 标记 = 24 - 9 - 6 = 9 位
```
