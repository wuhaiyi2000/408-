# 2017 年 408 真题：2017-43 整数溢出与 IEEE 754 单精度浮点数

> **核心考点：** unsigned 无符号数下溢、循环变量回绕、32 位 int
> 溢出、IEEE 754 单精度浮点数的有效精度、舍入规则、浮点数溢出与特殊值。

## 一、题目与已知条件

题目给出的函数：

``` c
int f1(unsigned n) {
    int sum = 1, power = 1;

    for (unsigned i = 0; i <= n - 1; i++) {
        power *= 2;
        sum += power;
    }

    return sum;
}
```

已知数学函数：

``` text
f(n) = 1 + 2 + 2^2 + ... + 2^n
     = 2^(n+1) - 1
```

将 `f1` 中的 `int` 都改为 `float`，得到函数 `f2`。

题目规定：

-   `unsigned` 和 `int` 都占 32 位；
-   `float` 使用 IEEE 754 单精度标准。

IEEE 754 单精度浮点数结构：

  字段           位数 作用
  ---------- -------- ------------------------------------
  符号位 S          1 表示正负
  阶码 E            8 表示指数，采用偏置值 127
  尾数 F           23 小数部分，规格化数有隐藏的最高位 1
  **总计**     **32** **1 + 8 + 23**

单精度浮点数的有效二进制精度为 **24 位**，即 23 位显式尾数加 1
位隐藏的最高位 1。

## 二、第（1）问：n=0 时，f1 为什么会死循环？将 i 和 n 改成 int 后还会死循环吗？

### 1. 原程序中 n 是 unsigned

当 `n=0` 时：

``` text
n - 1 = 0 - 1
```

因为 n 是 32 位无符号数，减法按模 2\^32 运算：

``` text
0 - 1 = 2^32 - 1
      = 4294967295
      = FFFFFFFFH
```

因此，循环条件：

``` c
i <= n - 1
```

变成：

``` c
i <= 4294967295
```

而 i 也是 32 位 unsigned，取值范围为：

``` text
0 ~ 4294967295
```

所以，i 的所有可能取值都满足这个条件。

当 i 达到最大值时：

``` text
i = FFFFFFFFH
i++ = FFFFFFFFH + 1
   = 00000000H
```

无符号数发生回绕，i 又变成 0，循环继续。

**结论：原程序在 n=0 时发生死循环。**

### 2. 如果将 i 和 n 都改成 int

此时：

``` c
for (int i = 0; i <= n - 1; i++)
```

当 n=0：

``` text
n - 1 = 0 - 1 = -1
```

第一次判断循环条件：

``` text
0 <= -1
```

条件不成立，因此循环体一次也不执行，直接返回：

``` text
sum = 1
```

**结论：将 i 和 n 都改成 int 后，n=0 时不会死循环，返回值为 1。**

### 本问易错点

-   `unsigned` 的 0 减 1 不会得到数学意义上的 -1，而是得到 `FFFFFFFFH`。
-   32 位 unsigned 的最大值是 `2^32-1`。
-   unsigned 自增到最大值再加 1，会回绕到 0。
-   int 是有符号数，`0-1=-1`，所以循环条件第一次判断就不成立。

## 三、第（2）问：f1(23) 和 f2(23) 的返回值是否相等？机器数分别是什么？

**答案：数值相等，均为 16777215；但整数和浮点数的机器数不同。**

### 1. 先计算数学结果

``` text
f(23) = 2^(23+1) - 1
      = 2^24 - 1
      = 16777215
```

### 2. f1(23)：int 整数计算

`f1` 中的 sum 和 power 都是 int。

结果：

``` text
f1(23) = 16777215
```

32 位整数机器数：

``` text
00000000 11111111 11111111 11111111
```

十六进制：

``` text
00FFFFFFH
```

### 3. f2(23)：float 浮点数计算

单精度浮点数有 24 位有效二进制精度。

在 0 到 2\^24 范围内，所有整数都可以精确表示。

而：

``` text
16777215 = 2^24 - 1
```

其二进制为 24 个连续的 1：

``` text
11111111 11111111 11111111
```

正好需要 24 位有效数字，所以可以被单精度浮点数精确表示。

因此：

``` text
f2(23) = 16777215.0
```

### 4. f2(23) 的 IEEE 754 机器数

将 16777215 写成规格化二进制：

``` text
16777215
= 1.11111111111111111111111 × 2^23
```

各字段：

  字段     内容
  -------- ---------------------------
  符号位   0
  阶码     23 + 127 = 150 = 10010110
  尾数     11111111111111111111111

拼接：

``` text
0 10010110 11111111111111111111111
```

十六进制：

``` text
4B7FFFFFH
```

### 本问答案

  函数             数值 32 位机器数
  -------- ------------ -------------
  f1(23)       16777215 `00FFFFFFH`
  f2(23)     16777215.0 `4B7FFFFFH`

**注意：数值相等，不代表机器数编码相同。**

## 四、第（3）问：为什么 f1(24) 和 f2(24) 不相等？

题目给出：

``` text
f1(24) = 33554431
f2(24) = 33554432.0
```

### 1. 整数结果

``` text
f(24) = 2^25 - 1
      = 33554432 - 1
      = 33554431
```

32 位 int 可以精确表示这个数，所以：

``` text
f1(24) = 33554431
```

### 2. 单精度浮点数为什么不能精确表示？

单精度浮点数只有 24 位有效二进制精度。

当数值达到 2\^24 后，浮点数相邻可表示值之间的间隔变为 2。

因此，在这一数值区间内，并不是每个整数都能表示。

目标值：

``` text
33554431
```

它两侧相邻的可表示浮点数是：

``` text
33554430
33554432
```

目标值正好处在两者中间：

``` text
33554431 - 33554430 = 1
33554432 - 33554431 = 1
```

### 3. IEEE 754 如何选择？

默认舍入方式是：

**舍入到最近值；如果正好处于中间，则选择有效数字最低位为偶数的那个数（ties
to even）。**

两个候选数中：

-   33554430 对应的有效数字最低位为 1；
-   33554432 对应的有效数字最低位为 0。

所以选择：

``` text
33554432
```

最终：

``` text
f2(24) = 33554432.0
```

### 本问结论

``` text
f1(24) = 33554431
f2(24) = 33554432.0
```

二者不相等，是因为单精度浮点数有效精度不足，发生了舍入。

## 五、第（4）问：为什么 f1(31) 返回 -1？若 f1(n) 返回值与 f(n) 相等，最大 n 是多少？

### 1. 为什么 f1(31) 返回 -1？

数学结果：

``` text
f(31) = 2^32 - 1
      = 4294967295
```

但 32 位有符号 int 的取值范围为：

``` text
-2^31 ~ 2^31 - 1
```

即：

``` text
-2147483648 ~ 2147483647
```

4294967295 超出了 int 的表示范围。

按照本题采用的 32 位补码机器运算模型，低 32 位结果为：

``` text
11111111 11111111 11111111 11111111
```

十六进制：

``` text
FFFFFFFFH
```

将其按 32 位补码解释：

``` text
FFFFFFFFH = -1
```

因此：

``` text
f1(31) = -1
```

**注意：** 严格按照标准 C 语言，signed int
溢出属于未定义行为。本题按计算机组成原理题目的 32 位补码回绕模型理解。

### 2. 求 f1(n) 返回值与数学结果相等时的最大 n

32 位有符号 int 最大值：

``` text
INT_MAX = 2^31 - 1
```

要让 f1(n) 的返回值与数学函数 f(n) 相等，必须满足：

``` text
2^(n+1) - 1 <= 2^31 - 1
```

两边加 1：

``` text
2^(n+1) <= 2^31
```

所以：

``` text
n + 1 <= 31
n <= 30
```

当 n=30：

``` text
f(30) = 2^31 - 1
      = 2147483647
```

恰好是 32 位 int 的最大值。

当 n=31 时，结果超出 int 的表示范围。

**答案：最大 n = 30。**

## 六、第（5）问：f2(127) 的机器数 7F800000H 表示什么？最大 n 分别是多少？

### 1. 判断 7F800000H 表示什么

将其转换为二进制：

``` text
7F800000H
= 01111111 10000000 00000000 00000000
```

按照 IEEE 754 单精度格式划分：

``` text
符号位：0
阶码：  11111111
尾数：  00000000000000000000000
```

IEEE 754 特殊值规则：

  阶码   尾数     表示
  ------ -------- -------------
  全 1   全 0     无穷大
  全 1   非全 0   NaN（非数）

本题：

-   符号位为 0；
-   阶码全 1；
-   尾数全 0。

所以：

``` text
7F800000H = +∞
```

**答案：正无穷大。**

### 2. 为什么 f2(127) 会溢出？

数学结果：

``` text
f(127) = 2^128 - 1
```

IEEE 754 单精度浮点数最大有限正数为：

``` text
(2 - 2^-23) × 2^127
= 2^128 - 2^104
```

比较：

``` text
2^128 - 1 > 2^128 - 2^104
```

因此，数学结果超过单精度浮点数最大有限范围。

在默认的最近值舍入模式下，结果变成正无穷大。

### 3. 若 f2(n) 的结果不溢出，最大 n 是多少？

分别看两个边界：

当 n=126：

``` text
f(126) = 2^127 - 1
```

该数可以舍入为有限的单精度浮点数。

当 n=127：

``` text
f(127) = 2^128 - 1
```

发生浮点数溢出，得到正无穷大。

因此：

``` text
最大 n = 126
```

### 4. 若 f2(n) 的结果精确（无舍入），最大 n 是多少？

这里要区分：

-   **不溢出：** 结果仍然是有限浮点数。
-   **精确无舍入：** 结果可以被单精度浮点数完全准确表示。

单精度浮点数有效精度为 24 位二进制。

当 n=23：

``` text
f(23) = 2^24 - 1
```

可以精确表示。

当 n=24：

``` text
f(24) = 2^25 - 1
```

不能精确表示，发生舍入。

因此：

``` text
最大 n = 23
```

### 本问最终答案

  条件                       最大 n
  ------------------------ --------
  f2(n) 结果不溢出              126
  f2(n) 结果精确、无舍入         23

## 八、408 考前必须掌握的知识点

### 1. 32 位 unsigned

``` text
取值范围：0 ~ 2^32-1

0 - 1 = FFFFFFFFH

FFFFFFFFH + 1 = 00000000H
```

无符号数按模 2\^32 运算。

### 2. 32 位 int

``` text
取值范围：-2^31 ~ 2^31-1

最大值：2147483647
最小值：-2147483648
```

在本题采用的补码回绕模型中：

``` text
FFFFFFFFH 按有符号数解释为 -1
```

### 3. IEEE 754 单精度浮点数

``` text
符号位：1 位
阶码：8 位
尾数：23 位
有效精度：24 位
阶码偏置值：127
```

### 4. 浮点数精度

-   24 位有效二进制精度意味着整数 0 到 2\^24 都能精确表示。
-   超过 2\^24 后，相邻浮点数的间隔会随数量级增大。
-   不能表示的数需要舍入。
-   默认舍入模式为最近偶数舍入。

### 5. IEEE 754 特殊值

  符号位   阶码   尾数     结果
  -------- ------ -------- ------
  0        全 1   全 0     +∞
  1        全 1   全 0     -∞
  任意     全 1   非全 0   NaN

### 6. 最容易混淆的三个概念

  概念         含义
  ------------ ------------------------------------------------
  整数溢出     整数结果超出对应类型的表示范围
  浮点数溢出   浮点数结果超出最大有限值，可能得到无穷大
  浮点数舍入   数值在表示范围内，但无法精确表示，需要取近似值

------------------------------------------------------------------------

## 九、一句话记忆

-   **unsigned：** 0-1 会下溢为全 1，循环变量自增到最大值后回绕到 0。
-   **int：** 32 位补码的最大正数为 2\^31-1。
-   **float：** 单精度只有 24 位有效二进制精度。
-   **舍入：** 33554431 不能被单精度精确表示，默认舍入为 33554432。
-   **溢出：** 7F800000H 表示正无穷大。
-   **本题三个重要边界：** int 最大正确 n=30；float 精确最大 n=23；float
    不溢出最大 n=126。
