# 2017-44 真题详解：汇编指令、CMP 与 CF 标志位

> 本题与 2017-43 的 C 程序对应，重点考查 RISC/CISC、机器指令长度、x86
> 汇编寻址、无符号减法的 CF 标志，以及整数移位和浮点数表示。

## 一、题目背景

2017-43 给出的 C 程序：

``` c
int f1(unsigned n) {
    int sum = 1, power = 1;
    for (unsigned i = 0; i <= n - 1; i++) {
        power *= 2;
        sum += power;
    }
    return sum;
}
```

2017-44 给出的关键汇编指令：

``` asm
cmp dword ptr [ebp-0Ch], ecx
shl edx, 1
```

题目说明机器按字节编址，`unsigned` 和 `int` 均为 32 位。

------------------------------------------------------------------------

## 二、第（1）问：计算机 M 是 RISC 还是 CISC？

**答案：CISC（复杂指令集计算机）。**

判断依据：

-   指令采用变长编码，指令长度不固定；
-   指令格式和寻址方式较复杂；
-   指令可以直接对内存操作数进行处理。

例如：

``` asm
cmp dword ptr [ebp-0Ch], ecx
```

该指令直接使用内存中的操作数与寄存器中的操作数进行比较，体现了较复杂的寻址和操作形式。

  RISC                 CISC
  -------------------- --------------------
  精简指令集           复杂指令集
  指令通常较简单       指令功能较复杂
  指令格式通常较规整   指令格式可能较复杂
  常见为定长指令       常见为变长指令

------------------------------------------------------------------------

## 三、第（2）问：计算机器指令代码总字节数

**答案：96 字节。**

已知：

-   第一条指令起始地址：`00401020H`
-   最后一条指令地址：`0040107FH`
-   最后一条指令为 `ret`
-   `ret` 的机器代码为 `C3`，占 1 字节

### 第一步：求最后一条指令结束后的地址

``` text
0040107FH + 1 = 00401080H
```

### 第二步：计算总长度

``` text
总字节数
= 最后一条指令结束后的地址 - 第一条指令起始地址
= 00401080H - 00401020H
= 60H
= 96 字节
```

因此，`f1` 的机器指令代码共占 **96 字节**。

**易错点：**
不能只用最后一条指令的起始地址减第一条指令的起始地址，否则会漏掉最后一条
`ret` 指令本身的 1 字节。

## 四、第（3）问：`cmp` 指令执行后 CF 是多少？

**答案：CF = 1。**

这是本题最重要的计算点，需要理解汇编语法、无符号数运算和借位标志。

### 1. 逐部分理解指令

``` asm
cmp dword ptr [ebp-0Ch], ecx
```

  部分          含义
  ------------- ---------------------------------------------------
  `cmp`         比较指令，本质上执行减法，但不保存减法结果
  `dword ptr`   指明操作数大小为一个双字，即 32 位，也就是 4 字节
  `[ebp-0Ch]`   访问内存地址 `EBP - 0CH` 中存储的数据
  `ecx`         ECX 寄存器中的数据

### 2. `[ebp-0Ch]` 是什么意思？

方括号 `[]` 表示访问内存。

假设：

``` text
EBP = 1000H
```

那么：

``` text
EBP - 0CH = 1000H - 000CH = 0FF4H
```

所以：

``` asm
[ebp-0Ch]
```

表示读取内存地址 `0FF4H` 中存储的内容。

要区分：

  写法          含义
  ------------- --------------------
  `ebp-0Ch`     计算出一个地址
  `[ebp-0Ch]`   读取该地址中的数据

结合本题给出的循环代码和汇编指令含义：

-   `[ebp-0Ch]` 对应循环变量 `i`；
-   `ecx` 中保存用于比较的 `n-1`。

因此，该指令相当于：

``` text
cmp i, n-1
```

### 3. `cmp A, B` 实际计算什么？

在 x86 汇编中：

``` asm
cmp A, B
```

本质上执行：

``` text
A - B
```

但不保存减法结果，只根据运算结果更新标志寄存器。

因此本题执行的是：

``` text
i - (n-1)
```

**注意操作数顺序：前面的操作数减去后面的操作数，不要反过来。**

### 4. 代入 `f1(0)`

函数调用：

``` c
f1(0);
```

`n` 是 32 位无符号数，因此：

``` text
n = 0
n - 1 = 00000000H - 00000001H
      = FFFFFFFFH
```

这里发生无符号整数下溢，结果按照 32 位无符号数的模 2\^32 运算得到
`FFFFFFFFH`。

当 `i=0` 时：

``` text
i = 00000000H
n-1 = FFFFFFFFH
```

执行 CMP：

``` text
00000000H - FFFFFFFFH
```

按 32 位结果计算：

``` text
00000000H - FFFFFFFFH = 00000001H
```

结果虽然是 `00000001H`，但无符号减法发生了借位。

所以：

``` text
CF = 1
```

### 5. CF 的判断规则

CF 是 Carry Flag（进位/借位标志）。

对无符号减法：

  情况                               CF
  -------------------------------- ----
  被减数小于减数，发生借位            1
  被减数大于或等于减数，没有借位      0

本题中：

``` text
0 < FFFFFFFFH
```

所以发生借位，`CF=1`。

**本问结论：CF = 1。**

## 五、第（4）问：`f2` 能否用 `shl` 实现 `power *= 2`？

**答案：不能。**

### 1. `shl` 的作用

第 23 条指令：

``` asm
shl edx, 1
```

含义是：将 EDX 寄存器中的二进制数整体逻辑左移 1 位。

对普通整数而言，在不考虑溢出等问题时，左移 1 位相当于乘以 2。

例如：

``` text
00000001
左移 1 位
00000010
```

也就是：

``` text
1 × 2 = 2
```

因此，在原函数 `f1` 中，`power` 是 `int`，可以用整数左移实现乘 2。

### 2. 为什么 `f2` 不可以？

题目将 `f1` 中的 `int` 全部改为 `float`，得到 `f2`。

此时 `power` 是 IEEE 754 单精度浮点数。单精度浮点数的 32 位结构：

  字段       位数 含义
  -------- ------ ----------------------
  符号位        1 表示正负
  阶码          8 表示指数
  尾数         23 表示有效数的小数部分

浮点数的 32 位编码不是普通整数的二进制数值表示。

如果直接执行：

``` asm
shl edx, 1
```

就会将整个浮点数编码整体左移，符号位、阶码和尾数都会受到影响，不能保证得到原浮点数乘以
2 的正确结果。

所以，`f2` 不能直接使用普通整数的 `shl` 指令实现
`power *= 2`，应使用浮点数乘法操作。

**本问结论：不能。**

补充理解：对于某些正常范围内的 IEEE 754 浮点数，乘以 2
可以理解为调整阶码；但这不等于把整个 32 位编码直接左移一位。

## 七、考前速记

### 1. 汇编语法

``` text
[地址]       表示访问该内存地址中的数据
dword ptr    32 位，即 4 字节
word ptr     16 位，即 2 字节
byte ptr     8 位，即 1 字节
```

### 2. CMP 指令

``` asm
cmp A, B
```

等价于：

``` text
A - B
```

只更新标志位，不保存运算结果。

### 3. 无符号减法与 CF

``` text
A < B  → 发生借位 → CF = 1
A >= B → 没有借位 → CF = 0
```

### 4. 整数移位与浮点数

``` text
整数左移 1 位：通常相当于乘以 2（需注意溢出）

float：IEEE 754 编码
不能直接将整个浮点数编码左移 1 位来实现乘以 2
```

### 5. 本题最容易错的地方

-   `cmp A,B` 是 `A-B`，不是 `B-A`。
-   `[ebp-0Ch]` 是访问内存，不是直接使用地址数值。
-   `dword ptr` 表示 32 位，不是 32 字节。
-   `unsigned` 的 `0-1` 得到 `FFFFFFFFH`，不是按有符号数解释的 `-1`。
-   无符号减法发生借位时，CF 为 1。
-   `shl` 可以用于整数乘 2，但不能直接用于 IEEE 754 浮点数编码。

## 八、一句话总结

这道题主要考查 **CISC 指令特征、机器指令长度计算、x86 汇编寻址与 CMP
标志位，以及整数和浮点数的底层表示差异**。

其中第（3）问要牢牢记住：`cmp dword ptr [ebp-0Ch], ecx` 在本题中就是
`i-(n-1)`；当 `f1(0)` 且 `i=0` 时发生无符号借位，所以 `CF=1`。
