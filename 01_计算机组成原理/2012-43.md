## 三、逐问解析

### 第（1）问：计算MIPS、每秒Cache缺失次数及主存带宽

#### ① 计算MIPS

**解题思路：**

MIPS表示CPU每秒执行的百万条指令数。

计算公式：

```text
MIPS = CPU主频(MHz) / CPI
```

代入数据：

```text
MIPS = 80 / 4 = 20
```

因此：

```text
MIPS = 20
```

表示CPU平均每秒执行20百万条指令，即2000万条指令。

#### ② 计算每秒Cache缺失次数

**第一步：计算CPU每秒执行的指令条数**

```text
每秒执行指令数 = MIPS * 10^6

              = 20 * 10^6

              = 20000000条/秒
```

**第二步：计算CPU每秒访存次数**

已知平均每条指令访存1.5次。

```text
每秒访存次数 = 每秒执行指令数 * 平均每条指令访存次数

             = 20000000 * 1.5

             = 30000000次/秒
```

**第三步：计算Cache缺失率**

```text
Cache缺失率 = 1 - Cache命中率

            = 1 - 99%

            = 1%
```

**第四步：计算每秒Cache缺失次数**

```text
每秒Cache缺失次数 = 每秒访存次数 * Cache缺失率

                  = 30000000 * 1%

                  = 300000次/秒
```

因此：

```text
每秒Cache缺失次数 = 300000次
```

#### ③ 计算满足CPU访存要求的主存带宽

**解题思路：**

Cache缺失时，需要从主存调入一个Cache块。

已知：
- 每秒Cache缺失300000次。
- 每次主存与Cache交换的数据块大小为16B。

计算公式：

```text
主存带宽 = 每秒Cache缺失次数 * 每次传输块大小
```

代入：

```text
主存带宽 = 300000 * 16

         = 4800000B/s

         = 4.8MB/s
```

因此：

```text
主存带宽至少为4.8MB/s
```

**第（1）问答案：**

- MIPS = 20
- 每秒Cache缺失次数 = 300000次
- 主存带宽至少为4.8MB/s

### 第（2）问：计算每秒缺页异常次数及DMA请求次数

#### ① 计算CPU平均每秒产生多少次缺页异常

**解题思路：**

题目说明：在Cache缺失、需要访问主存的情况下，存在0.0005%的缺页率。

因此，本题以Cache缺失次数作为计算缺页次数的基础。

首先，将百分数转换为小数：

```text
0.0005% = 0.000005
```

计算公式：

```text
每秒缺页次数 = 每秒Cache缺失次数 * 缺页率
```

代入：

```text
每秒缺页次数 = 300000 * 0.000005

             = 1.5次/秒
```

因此：

```text
每秒缺页异常次数 = 1.5次
```

#### ② 计算每次缺页需要多少次DMA传输

**解题思路：**

发生缺页异常后，需要从磁盘调入一个完整的页面。

已知：
- 页面大小为4KB。
- 磁盘I/O接口的数据缓冲寄存器为32位。

第一步：计算页面大小。

```text
4KB = 4 * 1024B = 4096B
```

第二步：计算每次DMA传输的数据量。

32位 = 4字节。

因此，每次DMA传输4B数据。

第三步：计算每次缺页需要的DMA请求次数。

```text
每次缺页DMA请求次数 = 页面大小 / 每次DMA传输的数据量

                    = 4096 / 4

                    = 1024次
```

因此：

```text
每次缺页需要1024次DMA请求
```

#### ③ 计算磁盘I/O接口平均每秒发出的DMA请求次数

已知：
- 每秒缺页1.5次。
- 每次缺页需要1024次DMA请求。

计算公式：

```text
每秒DMA请求次数 = 每秒缺页次数 * 每次缺页DMA请求次数
```

代入：

```text
每秒DMA请求次数 = 1.5 * 1024

                = 1536次/秒
```

因此：

```text
每秒DMA请求次数 = 1536次
```

**第（2）问答案：**

- 每秒缺页异常次数 = 1.5次
- 每次缺页需要1024次DMA请求
- 每秒DMA请求次数 = 1536次

### 第（3）问：CPU和DMA控制器同时请求使用存储器总线，哪个优先级更高？为什么？

**答案：DMA控制器的优先级更高。**

**原因：**

1. DMA控制器负责外设与主存之间的数据传输。
2. 外设的数据通常具有较强的时间要求，外设缓冲区容量有限。
3. 如果DMA请求长期得不到响应，可能导致外设数据缓冲区溢出，造成数据丢失。
4. CPU可以暂时等待存储器总线，通常不会因此造成数据丢失。

因此，当CPU和DMA控制器同时请求使用存储器总线时，通常优先响应DMA请求。

**补充：周期窃取（Cycle Stealing）**

周期窃取是DMA传输的一种方式。

其工作过程：

1. CPU和DMA控制器竞争存储器总线。
2. DMA控制器获得总线使用权。
3. DMA占用一个总线周期，完成一次数据传输。
4. CPU暂时让出总线。
5. DMA释放总线后，CPU继续使用总线。

注意：

DMA优先级高，不代表DMA一直占用总线，而是DMA需要传输数据时，可以优先获得总线使用权。

### 第（4）问：计算四体交叉存储模式下主存提供的最大带宽

**已知条件：**

- 主存采用四体交叉存储模式。
- 每个存储体的存储周期为50ns。
- 每隔1/4个存储周期启动一个存储体。
- 存储器总线宽度为32位。

#### ① 计算相邻两个存储体的启动间隔

四体交叉存储意味着每隔1/4个存储周期启动一个存储体。

计算公式：

```text
启动间隔 = 存储周期 / 存储体数量
```

代入：

```text
启动间隔 = 50ns / 4

         = 12.5ns
```

因此，相邻两个存储体的启动间隔为12.5ns。

#### ② 计算每次传输的数据量

已知存储器总线宽度为32位。

```text
32位 / 8 = 4B
```

因此，每次可以传输4B数据。

#### ③ 计算主存最大带宽

**解题思路：**

四体交叉存储时，每隔12.5ns就可以启动一个新的存储体。

在连续访问且各存储体正常交替工作的情况下，每隔12.5ns可以完成一次32位数据传输。

计算公式：

```text
最大带宽 = 每次传输的数据量 / 相邻传输时间间隔
```

代入：

```text
最大带宽 = 4B / 12.5ns

         = 4 / (12.5 * 10^-9)

         = 320000000B/s

         = 320MB/s
```

因此：

```text
主存最大带宽 = 320MB/s
```

#### ④ 理解四体交叉存储的工作原理

四个存储体可以交替工作：

| 时间 | 启动的存储体 |
|---|---|
| 0ns | M0 |
| 12.5ns | M1 |
| 25ns | M2 |
| 37.5ns | M3 |
| 50ns | M0 |
| 62.5ns | M1 |
| 75ns | M2 |
| 87.5ns | M3 |

每个存储体需要50ns才能完成一个存储周期。

但是，由于四个存储体交叉工作，可以每隔12.5ns启动一个新的存储体。

因此，连续访问时，每隔12.5ns就可以获得一次32位数据。

**注意区别：**

- 每个存储体的存储周期仍然是50ns。
- 相邻存储体的启动间隔是12.5ns。
- 四体交叉提高的是连续访问时的吞吐率。
- 并没有将单个存储体的存储周期缩短为12.5ns。

**第（4）问答案：**

```text
主存最大带宽 = 320MB/s
```

## 四、核心考点总结

### 1. MIPS计算

```text
MIPS = CPU主频(MHz) / CPI
```

表示CPU每秒执行的百万条指令数。

### 2. Cache缺失次数计算

```text
Cache缺失率 = 1 - Cache命中率

每秒访存次数 = 每秒执行指令数 * 平均每条指令访存次数

每秒Cache缺失次数 = 每秒访存次数 * Cache缺失率
```

### 3. 主存带宽计算

```text
主存带宽 = 每秒Cache缺失次数 * 每次传输块大小
```

注意：Cache缺失时，通常以Cache块为单位从主存调入数据。

### 4. 缺页异常与DMA请求

```text
每秒缺页次数 = 每秒相关访存次数 * 缺页率

每次缺页DMA请求次数 = 页面大小 / 每次DMA传输数据量

每秒DMA请求次数 = 每秒缺页次数 * 每次缺页DMA请求次数
```

常用单位换算：

```text
32位 = 4B

4KB = 4096B
```

### 5. DMA周期窃取

- DMA和CPU可以竞争存储器总线。
- 通常DMA优先级高于CPU。
- DMA每次占用一个总线周期完成数据传输。
- CPU暂时让出总线，之后继续执行。

### 6. 多体交叉存储

对于m体交叉存储：

```text
相邻存储体启动间隔 = 存储周期 / m
```

如果每次传输数据量为W字节：

```text
最大带宽 = W / (存储周期 / m)
```

四体交叉存储：

```text
最大带宽 = 4 * W / 存储周期
```

前提是各存储体能够持续交错工作，且总线带宽能够满足要求。

## 五、易错点

1. **MIPS计算：** 主频单位为MHz时，可以直接除以CPI。
2. **Cache缺失率：** 等于1减去命中率，不要直接使用命中率。
3. **主存带宽：** Cache缺失时，要考虑调入整个Cache块，而不是只考虑CPU需要的单个数据。
4. **缺页率：** 0.0005% = 0.000005，百分号不能遗漏。
5. **DMA传输宽度：** 32位对应4B，不是32B。
6. **缺页传输：** 每次缺页需要调入整个页面，而不是只调入一个Cache块。
7. **DMA周期窃取：** DMA暂时占用总线，不是永久占用总线。
8. **四体交叉存储：** 每隔1/4个存储周期启动一个存储体，不是每个存储体的存储周期缩短为原来的1/4。
9. **带宽计算：** 注意将ns转换为秒，避免单位换算错误。
