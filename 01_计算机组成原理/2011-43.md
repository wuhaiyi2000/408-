# 2011-43 补码运算与溢出判断

## 一、基本信息

- **一级主要考点：** 数据的表示与运算
- **二级考点：** 补码表示、无符号数模运算、补码加减法、溢出判断、ALU运算实现
- **题目分值：** 11分
- **题目类型：** 综合计算题

## 二、题目条件

某计算机字长为8位，运行以下C程序：

```c
unsigned int x = 134;
unsigned int y = 246;
int m = x;
int n = y;
unsigned int z1 = x - y;
unsigned int z2 = x + y;
int k1 = m - n;
int k2 = m + n;
```

编译器将8个8位寄存器R1～R8分别分配给变量x、y、m、n、z1、z2、k1、k2。

**注意：本题按计算机组成原理的8位补码运算模型处理，假设超出有符号表示范围的无符号数转换保留其二进制位模式。**

## 三、逐问解析

### 第（1）问：R1、R5、R6的内容

已知寄存器分配关系：

| 寄存器 | 对应变量 |
|---|---|
| R1 | x |
| R2 | y |
| R3 | m |
| R4 | n |
| R5 | z1 |
| R6 | z2 |
| R7 | k1 |
| R8 | k2 |

**① R1：x = 134**

134转换为8位二进制：

10000110B = 86H

因此：

R1 = 86H

**② R5：z1 = x - y**

由于x、y均为8位无符号数，运算结果按模256计算。

134 - 246 = -112

-112 mod 256 = 144

144转换为十六进制：

144 = 90H

因此：

R5 = 90H

**③ R6：z2 = x + y**

134 + 246 = 380

380 mod 256 = 124

124转换为十六进制：

124 = 7CH

因此：

R6 = 7CH

**本问答案：**

- R1 = 86H
- R5 = 90H
- R6 = 7CH

### 第（2）问：变量m和k1的值

**① 计算m**

m = x = 134

由于int为8位带符号补码，134超出其表示范围（-128～127）。

134的二进制：

10000110B

最高位为1，表示负数。

求其对应的绝对值：

- 按位取反：01111001
- 加1：01111010 = 122

所以：

m = -122

**② 计算k1**

k1 = m - n

先计算n：

n的二进制位模式与y相同：

11110110B

按补码解释：

按位取反：00001001

加1：00001010 = 10

因此：

n = -10

代入：

k1 = -122 - (-10)

k1 = -112

-112在8位补码表示范围内，没有发生溢出。

**本问答案：**

- m = -122
- k1 = -112

### 第（3）问：四种加减运算能否使用同一个加法器？

题目涉及四种运算：

1. 带符号整数加法
2. 带符号整数减法
3. 无符号整数加法
4. 无符号整数减法

**答案：可以使用同一个加法器及辅助电路实现。**

核心原理：补码减法可以转换为补码加法。

公式：

A - B = A + (~B) + 1

其中~B表示按位取反。

因此，ALU可以通过控制电路实现：

| 运算 | B操作数处理 | 进位输入Cin |
|---|---|---|
| 加法 | B不变 | 0 |
| 减法 | B按位取反 | 1 |

带符号和无符号运算的底层二进制加减过程相同。

区别在于：
- 带符号数：需要判断有符号溢出。
- 无符号数：需要判断最高位进位或借位。

因此，四种运算可以共用一个加法器，通过辅助控制电路完成。

### 第（4）问：哪些带符号整数运算发生溢出？

8位带符号补码的表示范围：

-128～127

判断各条语句：

**① m = x**

属于无符号数向带符号数的转换，不属于带符号整数加减运算。

**② n = y**

同上。

**③ k1 = m - n**

-122 - (-10) = -112

-112处于-128～127范围内。

因此，没有溢出。

**④ k2 = m + n**

-122 + (-10) = -132

-132小于-128，超出8位带符号补码的表示范围。

因此，发生溢出。

从二进制角度验证：

```text
m = 10000110
n = 11110110

  10000110
+ 11110110
-----------
1 01111100
```

保留低8位：

01111100B = 124

两个负数相加，结果却变成正数，发生有符号数溢出。

**本问答案：**

只有 k2 = m + n 发生有符号整数溢出。

## 四、核心考点总结

### 1. 数值表示范围

| 类型 | 8位表示范围 |
|---|---|
| 无符号数 | 0～255 |
| 带符号补码 | -128～127 |

### 2. 无符号数模运算

n位无符号数：

结果 = 实际运算结果 mod 2^n

8位无符号数：

结果 = 实际运算结果 mod 256

### 3. 补码加减法

- 正数补码：原码不变。
- 负数补码：按位取反，再加1。
- 减法实现：A - B = A + (~B) + 1。

### 4. 溢出判断

| 运算类型 | 判断方法 |
|---|---|
| 有符号加法 | 同号相加，结果异号 |
| 有符号减法 | 异号相减，结果与被减数异号 |
| 无符号加法 | 最高位产生进位 |
| 无符号减法 | 产生借位 |

### 5. ALU运算实现

带符号和无符号整数的加减运算可以共用一个补码加法器。

区别在于结果解释和溢出判断方式。

## 五、易错点

1. 无符号数运算结果需要按模2^n计算。
2. 8位补码的范围是-128～127，而不是-127～127。
3. 最高位产生进位，不代表有符号数一定发生溢出。
4. 有符号数溢出看符号变化，无符号数溢出看进位或借位。
5. 同一个二进制结果，按照有符号数和无符号数解释，数值可能不同。
6. 本题中k2的结果虽然保留为01111100（124），但数学上的真实结果是-132，因此发生溢出。
