# 2016 年 408 真题：异步串行通信与中断 I/O（2016-44）

> 本题考查异步串行通信字符格式、设备传输速率、中断 I/O 时间计算，以及
> CPU 与外设并行工作。
>
> **核心区别：** 第一问计算设备 D 持续工作时的理论传输能力；第二问考虑
> CPU 每次处理中断后，执行到第 15 条指令才重新启动设备所产生的额外时间。

## 一、题目条件整理

  已知条件                                 数值
  ----------------------------- ---------------
  CPU 主频                               50 MHz
  CPI                                         4
  ASCII 数据位                             7 位
  奇偶校验位                               1 位
  停止位                                   1 位
  异步串行起始位                           1 位
  启动设备到字符送入 I/O 端口            0.5 ms
  每收到一个字符产生的中断                 1 次
  中断响应时间                    10 个时钟周期
  中断服务程序                        20 条指令
  启动下一次设备工作的指令             第 15 条
  需要读取的字符数                      1000 个

------------------------------------------------------------------------

## 二、第（1）问：每个字符传输多少位？每秒最多传输多少个字符？

### 1. 每个字符需要传输多少位？

异步串行通信一个字符包含：

-   起始位：1 位
-   数据位：7 位
-   奇偶校验位：1 位
-   停止位：1 位

因此：

``` text
1 + 7 + 1 + 1 = 10 位
```

**答案：每个字符需要传输 10 位。**

注意：题目说的是 7 位 ASCII
数据，但串行线路上还要传输起始位、奇偶校验位和停止位，不能只按 7
位计算。

### 2. 每秒最多向 I/O 端口送入多少个字符？

题目给出，从设备 D 接收到启动命令，到一个字符送入 I/O 端口，需要 0.5
ms。

``` text
0.5 ms = 0.0005 s

每秒最多完成的字符数 = 1 ÷ 0.0005
                     = 2000 个字符/秒
```

**答案：设备 D 持续工作时，每秒最多向 I/O 端口送入 2000 个字符。**

### 3. 对应的串行通信速率

每个字符占用 10 位，每秒传输 2000 个字符：

``` text
10 × 2000 = 20000 bit/s = 20 kbit/s
```

### 4. 重要辨析：2000 个字符/秒是设备自身的理论速率

第一问只根据设备给出的 0.5 ms 计算，求的是**设备 D
持续工作时的理论传输能力**，没有计入 CPU 重新启动设备的时间。

第二问才考虑 CPU 的中断服务程序对实际字符间隔的影响。

如果每个字符完成后，都需要 CPU 再次启动设备，那么相邻字符的完成间隔会比
0.5 ms 略长。

------------------------------------------------------------------------

## 三、第（2）问：CPU 读取 1000 个字符需要多少时间？

### 1. 计算 CPU 时钟周期

CPU 主频为 50 MHz：

``` text
时钟周期 = 1 ÷ 50 MHz
         = 20 ns
```

所以：

``` text
1 个时钟周期 = 20 ns
```

### 2. 计算执行一条指令的时间

CPI = 4，表示平均每条指令需要 4 个时钟周期：

``` text
每条指令需要 4 个时钟周期
每条指令执行时间 = 4 × 20 ns = 80 ns
```

### 3. 设备接收一个字符需要多少个时钟周期？

设备接收一个字符需要 0.5 ms：

``` text
0.5 ms = 500000 ns

500000 ns ÷ 20 ns = 25000 个时钟周期
```

**结论：设备每次接收一个字符需要 25000 个时钟周期。**

### 4. 一次中断响应及完整服务程序需要多少周期？

中断响应时间为 10 个时钟周期。

中断服务程序有 20 条指令，每条指令平均需要 4 个时钟周期：

``` text
20 × 4 = 80 个时钟周期
```

因此一次中断响应及完整服务程序共需要：

``` text
10 + 80 = 90 个时钟周期
```

------------------------------------------------------------------------

## 四、为什么第 15 条指令特别重要？

题目说明：中断服务程序的第 15 条指令会启动设备 D 工作。

这意味着 CPU 不必等到 20 条指令全部执行完，才启动下一次字符接收。

### 1. 启动下一次设备工作需要多少周期？

中断响应需要 10 个周期。

执行前 15 条指令需要：

``` text
15 × 4 = 60 个周期
```

从当前字符到达、产生中断请求开始，到设备被重新启动，需要：

``` text
10 + 60 = 70 个时钟周期
```

### 2. 剩余 5 条指令与设备工作重叠

第 15 条指令启动设备后，CPU 还要执行剩余 5 条指令：

``` text
(20 - 15) × 4 = 20 个时钟周期
```

此时设备已经开始接收下一个字符，需要 25000 个周期才能完成。

所以：

-   CPU 执行剩余 5 条指令：20 个周期。
-   外设接收下一个字符：25000 个周期。
-   两者可以并行进行。

CPU 会先完成当前中断服务程序，之后等待下一个字符产生中断。

### 3. 时间线

``` text
当前字符到达 I/O 端口
        │
        ▼
中断响应：10 周期
        │
        ▼
执行前 15 条指令：60 周期
        │
        ▼
启动下一次设备工作
        │
        ├──────── 外设接收下一个字符：25000 周期 ────────┐
        │                                                │
        ▼                                                │
执行剩余 5 条指令：20 周期                               │
        │                                                │
        ▼                                                │
中断服务程序结束                                         │
        │                                                │
        └──────────── 等待外设完成 ──────────────────────┘
                                                         │
                                                         ▼
                                                下一个字符到达并申请中断
```

**关键结论：** 下一次设备工作在第 15 条指令处启动，因此剩余 5 条指令的
20 个周期与外设接收下一个字符的时间重叠，不能重复累加到总经过时间中。

------------------------------------------------------------------------

## 五、完成 1000 个字符，总共需要多少时钟周期？

分成三个部分计算。

### 1. 第一个字符

开始时先启动设备，接收第一个字符需要：

``` text
25000 个时钟周期
```

### 2. 前 999 个字符完成后的中断处理

前 999 个字符完成后，CPU 需要处理中断，并在第 15
条指令处启动下一个字符。

每次从中断请求到启动下一次设备工作，需要：

``` text
中断响应：10 周期
前 15 条指令：15 × 4 = 60 周期

合计：10 + 60 = 70 周期
```

前 999 次共需要：

``` text
999 × 70 = 69930 个时钟周期
```

注意：这里不是每次都加 90 周期，因为启动下一次设备后，剩余 5
条指令会与外设工作重叠。

### 3. 最后一个字符完成后的中断处理

第 1000 个字符到达后，还需要最后一次中断响应和服务程序处理：

``` text
中断响应：10 周期
20 条指令：20 × 4 = 80 周期

合计：10 + 80 = 90 周期
```

### 4. 总经过时间

``` text
第一个字符：25000 × 1

前 999 次中断后启动下一次设备：999 × 70 = 69930

最后一次中断处理：90

总计：
25000 × 1000 + 999 × 70 + 90
= 25070020 个时钟周期
```

**答案：完成 1000 个字符任务，约需要 25070020 个时钟周期。**

### 5. 换算成实际时间

``` text
总时间 = 25070020 ÷ 50000000
       = 0.5014004 s
```

即约 **0.5014 秒**。

------------------------------------------------------------------------

## 六、CPU 用于完成这项任务的时间是多少个时钟周期？

这一问与上一问不同。

上一问计算的是整个任务从开始到结束的总经过时间；这一问只计算 CPU
真正用于中断响应和执行中断服务程序的时间。

每个字符产生一次中断，共 1000 次。

每次中断：

``` text
中断响应：10 周期
中断服务程序：20 × 4 = 80 周期

每次合计：90 周期
```

1000 次中断：

``` text
1000 × 90 = 90000 个时钟周期
```

**答案：CPU 用于完成这项任务的时间约为 90000 个时钟周期。**

换算成实际时间：

``` text
90000 × 20 ns = 1.8 ms
```

### 两种时间不要混淆

  项目                                  时钟周期      实际时间
  ----------------------------------- ---------- -------------
  整个任务总经过时间                    25070020   0.5014004 s
  CPU 中断响应及服务时间                   90000        1.8 ms
  1000 次设备接收字符的累计工作时间     25000000         0.5 s

CPU 与外设可以并行工作，因此不能把 CPU
工作时间和外设工作时间简单相加作为总经过时间。

------------------------------------------------------------------------

## 七、第一问的 2000 个字符/秒与第二问的实际速度有什么区别？

这是本题特别容易混淆的地方。

### 1. 设备自身持续工作时的理论速率

每个字符需要 0.5 ms：

``` text
1 ÷ 0.0005 = 2000 个字符/秒
```

这是第一问的答案。

### 2. CPU 重新启动设备时的实际字符间隔

每个字符完成后，CPU 需要：

``` text
中断响应：10 周期
执行前 15 条指令：60 周期

合计：70 周期
```

70 个时钟周期换算成时间：

``` text
70 × 20 ns = 1400 ns = 1.4 μs
```

因此，按照第二问的逐字符启动机制，相邻两个字符完成的间隔约为：

``` text
0.5 ms + 1.4 μs
= 0.5014 ms
```

实际平均速率约为：

``` text
1 ÷ 0.0005014 ≈ 1994.4 个字符/秒
```

  比较                            第一问   第二问的逐字符启动机制
  ------------------------- ------------ ------------------------
  单个字符的设备工作时间          0.5 ms                   0.5 ms
  重新启动设备的 CPU 开销           不计                   1.4 μs
  相邻字符完成间隔                0.5 ms                0.5014 ms
  字符速率                    2000 个/秒          约 1994.4 个/秒

**结论：2000 个字符/秒是设备持续工作时的理论传输能力；如果每个字符都需要
CPU 重新启动设备，则实际吞吐率会略低。**

------------------------------------------------------------------------

## 八、中断响应阶段，CPU 进行了哪些操作？

按照本题参考答案，中断响应阶段 CPU 主要完成以下四项操作：

1. **确定中断源：** 查询中断源编码，确定是谁提出了中断请求。
2. **关中断：** 暂时不接受新的中断请求，禁止新的中断打断当前中断响应过程。
3. **保护程序断点：** 保存当前程序计数器（PC）的内容，记住被中断程序应该从哪里继续执行。
4. **转至中断服务程序：** 根据中断源编码，跳转到相应中断服务程序的入口地址。

### 记忆顺序

```text
确定中断源
    ↓
关中断
    ↓
保护程序断点（保存 PC）
    ↓
转至中断服务程序
```

答题时按照这四步及其顺序作答。这里的“保护程序断点”特指保存 PC，供中断处理结束后返回原程序继续执行。

### 中断响应阶段与中断服务阶段的区别

  --------------------------------------------------------------------------------------
  阶段                                主要任务
  ----------------------------------- --------------------------------------------------
  中断响应阶段                        保存必要现场、识别中断源、转入中断服务程序

  中断服务阶段                        执行中断服务程序，读取数据、处理数据、启动下一次
                                      I/O 等
  --------------------------------------------------------------------------------------

注意：不同 CPU 的具体现场保护方式可能不同。408
复习时重点掌握上述基本过程。

## 十、408 考前重点记忆

### 1. 异步串行通信

-   一个字符的传输位数 = 起始位 + 数据位 + 校验位 + 停止位。
-   本题：1 + 7 + 1 + 1 = 10 位。
-   设备持续工作时的字符速率 = 1 ÷ 每字符所需时间。

### 2. CPI 与主频

``` text
时钟周期 = 1 ÷ CPU 主频

每条指令平均时钟周期数 = CPI

每条指令平均执行时间 = CPI × 时钟周期
```

### 3. 中断 I/O 时间计算

-   每个字符到达 I/O 端口后产生一次中断。
-   总中断次数 = 字符数。
-   每次中断的 CPU 开销 = 中断响应时间 + 中断服务程序执行时间。
-   如果中断服务程序在中途启动下一次设备工作，要考虑 CPU
    与外设的时间重叠。

### 4. 时间重叠判断

看到题目给出"第几条指令启动设备"，要立刻拆分：

-   启动设备之前：CPU 开销会推迟下一次设备工作。
-   启动设备之后：CPU 剩余指令可能与外设工作重叠。

**本题核心记忆：第 15 条指令启动设备，所以每次中断后启动下一次接收需要
10 + 15 × 4 = 70 个周期；剩余 5 条指令的 20 个周期与外设工作重叠。**
